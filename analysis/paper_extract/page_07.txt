4. Experimental Section
Data Generation and Training of GNN:
In the data generation stage, we
have collected 10 648 sets of data using CST Microwave Studio software
guided by sliding window method. The whole dataset is shuﬄed, where
80% are blindly selected as the training set and the remaining 20% are
used for validation and testing. We use the Deep Graph Library (DGL) to
implement the GNN and convert all data into graphs to meet its input data
format. The GNN is trained using Python version 3.10 and Pytorch frame-
work on a server (GeForce RTX 4090 GPU and an AMD Ryzen Threadripper
PRO 5975WX 32-Cores with 128 GB RAM, running on a Windows operat-
ing system).
Control Module for Intelligent Metasurfaces System:
Independent volt-
age control for 400-unit cells can be achieved through Verilog program-
ming in Vivado 2018.3. The program is written into the FPGA (model:
PYNQ-Z2), which generates serial signals. In Verilog code, 1 and 0 rep-
resent high and low voltage levels respectively, corresponding to FPGA
outputs of 3.3 and 0 V. The control circuit then converts the serial signals
into parallel signals, thereby enabling independent control of the unit cells.
