# 2026-11-19 工作日志

## 一、曲面阵列工作包（r42r5_bundle）

工作区新增 `r42r5_bundle/`（可迁移的三文件包），实现**曲面阵列**的建模—仿真—批量：

| 文件 | 作用 |
|---|---|
| `r42r5_curved.py`（35 KB） | 建模器：生成完整 CST VBA（几何 + 求解器 + 导出），纯 Python 不依赖 CST |
| `run_bas_case.py`（12 KB） | 单例执行器：切段驱动 CST 建几何 / 求解 / 自检 / 导出 6 列复场 |
| `curved_batch.py`（14 KB） | 批量：`--n` 阵列规模、`--count` 组数，带**相位门**、断点续跑、元数据指纹 |
| `README.md`（8 KB） | 环境要求（TLM license、CST 库自动定位）、快速开始、dry-run 用法 |

设计上值得注意的两点：
1. **相位门**：先跑 `uniform0` / `uniform1` 各一例，相位不达标就退出，不浪费批量时间；
2. `--dry-run` 可只生成宏、不碰 CST。

这正好接上了计划里的"步骤 02/03：曲面几何与有限阵列"。
