## 1 M1：Γ_eff = Γ_isol + mean(Δq)

**1.1 与 B3 的恒等式冲突（数对不上）。** B3（pipeline.py:78-80）逐图去均值 ⇒ Σ_n Δq_n ≡ 0，按状态分组后必有 n0·m0+n1·m1 = 0。引用的 m0=+0.032+0.153j、m1=-0.031-0.146j 代入 case 0000 的 216/184（演示 §2）：216m0+184m1 = **+1.21+6.18j**，即每节点 0.0158，占 abs(m0)=0.156 的 **10%**〔手算〕。只有把两态**不加权**平均（0.5m0+0.5m1=0.0005+0.0035j）才勉强自洽 ⇒ 这两个数是"逐例均值再平均"，不是节点加权均值；而 M1 要按节点加进去。照抄它们等于往镜面里塞一个 Σ_m=1.21+6.18j 的假 DC（镜面 +0.37 dB，最坏 +1.7 dB）。

**1.2 "随状态反号"不是测量，是 B3 的数学后果。** 近均衡码下 m1 = -(n0/n1)m0，反号是强制的。这条"证据"不成立。

**1.3 它的可观测量 = +3.5% 增益，不是"23% 修正"。** q 的分解只有两项：DC = (n0Γ0+n1Γ1)/N（即 b 那一支）与对比 ΔΓ=Γ0-Γ1。M1 加的是 ±d，d=(m0-m1)/2=0.0315+0.1495j：DC 不变、ΔΓ→ΔΓ+2d。ΔΓ=1.7190∠-5.35°，2d=0.063+0.299j ⇒ 新对比 1.7799∠+4.47°：**+3.54% 幅度、+9.8° 旋转**〔手算〕。整条方向图 ∝ abs(ΔΓ)^2，旋转是全局相位不可观测 ⇒ **全部效果 = +0.30 dB 电平**。它严格不动 DC，所以动不了 13.8 dB 的镜面缺口。

**1.4 与 224°/b：不是两种写法，是同一枚硬币的两面，而它拿错了面。** 224° 的量是 **DC**：abs(DC) = abs(Γ)·abs(cos(Δφ/2))。取 abs(Γ)=1.002、Δφ=224°：abs(DC)=0.3746 ⇒ 400·abs(DC)=149.8 ⇒ σ=(0.023176×149.8)^2 = **+10.81 dBsm**（f0=0.5；case 0000 的 216/184 给 400·abs(DC)=153.1、+11.00），实测 +10.80〔手算，C 见 radiation.py:44-46〕。即 **"224°+abs(Γ)=1.002" 与 "b=0.374∠265°" 是同一个数的两种写法**，b 不是独立模式。反过来，M1 的 ±d 是**去均值后的对比项**，与 DC 正交 ⇒ 它与 224° 无关，也补不了镜面。真正的重复计算风险不在 B3，而在 **M1（若按 224° 实现）+ b**：两者往同一个 DC 里加，会多算 20log10((0.33+0.37)/0.33) ≈ **+6.5 dB**。

**1.5 两个硬伤。** ① 泄漏：m0/m1 来自 cst/diagnose_demo.py:35 在 **44 个 test 样本**上的统计（演示 §10.1），烘进库后再在这 44 例报 spec_err。② 未收敛：那 5 个 epoch 的 train loss 仍在降（9.02→4.10，演示 §10），文档自己写"不是最终性能"；冻结一个未收敛残差的均值＝冻结训练伪影。

**1.6 最小执行（0 CST、0 训练）。** ① **单参数判别**：只加实标量 g（q0←g·q0），train 上 1 维扫描 g∈[0.98,1.15]；若最优 g≈1.035 且 rmse 与 M1 相同 ⇒ M1 全部内容就是幅度标定。② **224° 判别**：把 GAMMA_PH_DEG 改 (-5.3, 218.7)、振幅扫 (0.867 / 0.90 / 1.002)，**直接跑 M0 不训练**，手算预测镜面 +9.5~9.7 / +10.0 / +10.8~11.0（实测 +10.80）。命中 ⇒ 224° 成立、b 应归零；不命中 ⇒ M1 更无理由。③ 先统一振幅口径：theory/REPORT.md:397-407 的 1.002 是**标量倾角**口径反演的；同一反演在代码的 vector 口径下给 **0.90**（-7.257+0.70，numbers.json）。两者差 0.5 dB，正好是 M1 想修的量级。

## 2 A1/A2：2x1 超胞 Floquet

**2.1 法向入射只能给 3 个数，不是 4 个复 Γ。** 2x1 超胞法向：两格等相位激励，0 阶反射 R01=(Γ(0|1)+Γ(1|0))/2；4 次求解只给 R00=Γ(0|0)、R11=Γ(1|1)、R01=R10=两者之半。差模在 ±1 阶，而 2P=28 mm ⇒ c/(2P)=**10.71 GHz**，10 GHz 下 ±1 阶是**凋落波**，端口看不到差模——这就是法向无法分离两态的原因。要分离必须加斜入射（±30°：kP sinθ=84°，两格相位差 ±42°，条件数好）。所以"4 种态组合→4 个复 Γ"不成立，最多给 Γ00、Γ11 与 ε=R01-(R00+R11)/2。

**2.2 超胞形状错了：2x1 是条纹光栅，数据集是 2x2 块。** 数据 block=2（dataset.py:169；演示 §2），单元以 **2x2 同态块**出现。2x1 超胞在 y 方向周期 P ⇒ 每格的 y 邻居是"自己"、x 邻居是对方 ⇒ 测的是**条纹光栅**耦合，这种环境在语料里不存在。正确对象是 2x2（或 4x4）超胞 + 中心周围随机码；theory/REPORT.md:526 已写明"3x3 或 5x5 混合环境超胞"，A1 反而退化了。

**2.3 更要紧的既有事实：Γ 本来就是"无限均匀阵"的值。** unit_library.py:4-8 与 theory/REPORT.md:79 写明 Γ 来自**周期单元** Floquet ⇒ 全 0/全 1 的"阵中 Γ"早已测过，就是 **179.95°**。因此 224°（或 REPORT.md:493 的 137°）**不可能是均匀环境效应**，只能是混合环境的平均场。A1 的 00/11 只能当**零检**（应回到 179.95°±2°），不产生新物理。这也解释了 b 为何近似常数：i.i.d. 码下 4 种邻居组合的边缘分布固定（各 1/4），平均场与具体码无关 ⇒ DC 与码无关。**D3 的"常数"是这个结构的推论，不是巧合。**

**2.4 可执行版本（4 次求解，20 min）。** ① 2x2 超胞、法向：[0 0;0 0]、[1 1;1 1]（零检），[0 0;1 1]、[0 1;1 0]（两种混合环境）。② 端口/网格/参考面与旧单元胞 run **逐位相同**，否则 -1.24 dB 的数值损耗会变成假 ΔΓ。③ 判据别用 abs(Γ00-Γ01)>0.05，改成"把 ε 喂进算子后 6-60° 分带 abs(Δσ) > 0.3 dB"（0.05 在随机码上折 ~0.3-0.6 dB，量级对，但必须落在可观测量上）。④ 频率上限 10.7 GHz；A6 若含 11 GHz，2P 超胞进多模，必须换口径。

**2.5 A2 前置未就位（与现状冲突）。** 管线查库不传角度：build_graph.py:132 library(case.bits.ravel())，baseline.py:38 同；(θ,φ) 双线性表是死代码（geometry_representation.md:62 已列）。A1 测出的斜入射 Γ 现在**无处可去**——A2 必须先有"角度查询"这条线，否则表里只剩法向一列。

## 3 A3/A4：态依赖

**3.1 代数上 A3 ⊂ A4 的一阶。** message_passing.py:41：m=MLP([h_src,h_dst,e])；门控乘在 m 上再 sum，节点 j 收到 Σ_i c[s_i,s_j]m_ij。当 m 对 s_i 的显式依赖只经 h_src 的 bit/Γ，一阶项 = c[0,s_j](8-k)+c[1,s_j]k，k=8·mean(bit_nbr)——**正是 A4 那一列**乘一个 dst 态权重。A3 真正多出的只有 s_src·s_dst 的双线性项（2 个实自由度），不是 8 个。二者同时做就是重复表达。

**3.2 判据指错了量。** abs(Γ00-Γ01)>0.05 是"换一个邻居态"的差（pair 耦合 ε），而 13.8 dB 缺口由 DC 决定、DC 由 abs(Γ0+Γ1) 决定。该盯 abs((Γ00+Γ11)/2) 与 arg(Γ11/Γ00)（→224°/137°）。且该判据在法向**测不出**（2.1），按 2.2 的条纹光栅测出的 ε 也不对应语料环境。

**3.3 A4 的问题不在物理，在共线。** 2x2 块 ⇒ 8 邻居里 3 个是"自己"⇒ E[mean(bit_nbr)|bit]=(3/8)bit+(5/8)·0.5 ⇒ 与 bit_signed 相关 ≈0.80。它能给的是剩下 5/8 的随机环境，收益不大。建议文档引的"Δq 与邻居态相关仅 -0.06/-0.28"在 B3 去均值 + 2x2 块下会被稀释，不能当作"耦合弱"的证据（来源未给，未复核）。

## 4 A5：单元方向图

**4.1 46 维 θ 乘性修正 ≡ 逐 θ 的损失重加权。** 算子已含倾角 p_θ=cosθcosφ（radiation.py:72-80）；再乘 f(θ) 得 σ_pred(θ,φ)→f^2(θ)σ_pred(θ,φ)——**对所有 φ 同一个因子**，与改损失/指标的 θ 权重在数学上不可区分（losses.py:35-47 本就有 sinθ+0.2 与主瓣 x3）。46 个 θ 档、46 个自由参数、判据又是分带 rmse ⇒ 每档平均残差必被抹平，"掉一半"是恒等式。**必须改成 θ 外推**：只用 θ≤50° 拟合，考 60-90°。

**4.2 60-90° 的缺口不是单元方向图能解释的。** 演示 §5.3：(90°,0°) 模型 -60（地板）、实测 -17.89 ⇒ 缺口 ≥**42 dB**；无源单元方向图相对理想口径只能 ≤1（≤0 dB），要 +42 dB 就是凭空增益。该段误差来自**有限地板边缘绕射 + cosθ 投影掠射退化**（gnn_architecture.md:74-75、后续工作计划.md:199 已记录"cosθ 类已掉到 -40 以下"），是**非局部**效应（随周长/面积比变），拟合成 f(θ) 后不可能外推到 10x10/40x40。另：1-bit 两态贴片半径不同（4.7/2.0 mm），单元方向图本身**态依赖**，单个 f(θ) 又是态平均。

**4.3 正确判别。** 从 CST 直接取单元方向图（法向 + 斜入射单元胞 Floquet，与 A1 同一批 run），而不是从 44 例方向图反拟合；若要拟合，只能 train、θ≤50° 拟合、60-90° 外推，并要求 f(θ) 单调不增（物理先验）。

## 5 M5：缓存路径矩阵 D

- 事实修正：当前只有 **1 套核**（radiation.py:205-216：一个 phase 按角度分块），不是 5 套；5 套只在 A6 多频后出现。
- 代价：D 是 400x8280=3.3 M，float64 26 MB（float32 13 MB，与说明一致）。前向现在是 4 次 BLAS matmul；改 cos(kD) 后每次前向多 6.6 M（同频）到 53 M（批内混频）次 sin/cos，CPU 上通常 2-5x 变慢〔估算，需 benchmark〕。单频下**零收益**。
- 物理上更要紧：M5 只改**传播子**，频率依赖全在 Γ(f)（unit_library.py:44 的 freq 参数是空的）与 b(f)（带内 8.6 dB、f0=9.60、Q=4.86，后续工作计划.md:196-197）。"任意频率免费"不成立。
- 替代：按 (几何, f) 缓存 cos/sin，键为 f；5 频点 float32 约 65 MB，可接受。M4 先把 per-case 的 f 接进算子（build_graph.py:183 与 experiment 的 op 构造）。

## 6 D3：冻结 b

**6.1 0.33-0.41 里有多少是物理。** 〔手算〕Δφ=224°、abs(Γ)=1.002、f0=0.50~0.54 ⇒ abs(DC)=0.375~0.383；f0 抖 ±0.05（100 个宏比特 i.i.d.，dataset_gen.py:79-80 的 randint 就是这个标准差）⇒ **abs(DC) 只动 ≤2%，但相位摆 ±12°**。观测：4 个码 oracle 拟合 0.330-0.410（±11%）、相位 266-282°（后续工作计划.md:186-189），幅度摆幅是物理预测（±2%）的 5 倍 ⇒ dB 域拟合噪声主导；学到的 b 是 0.374±0.011（±3%，与 abs(Γ)=1.002+224° 的 0.375 一致）但**相位 ±0.1°（比 ±12° 小两个量级）**⇒ 学到的 b 在相位上被冻住了，**这是欠拟合指纹，不是物理常数**。

**6.2 机理：mean-pool 看不见占空比。** 全局支路 mean-pool 400 节点（residual_gnn.py:66-70），池化后的码间起伏 O(1/√400)=5%，正好给 ±3% 的 abs(b)；但占空比信息被平均掉。所以 corr(b_learned,b_oracle)=-0.197 不能证明 b 是常数：oracle 的逐例摆幅（0.0218）比占空比模型预测（~0.004）大 5 倍，本身含大量非 b 的模型误差，不能当参照。**该做的是把 mean(bit)（1 个标量）喂给全局支路，而不是冻结。**

**6.3 冻结后 b 的相位还重要吗？** 重要，但它不是规范自由度：只有 q 的**全局**相位不可观测；b 相对 q0 的相位决定 0-6° 瓣的形状与干涉。手算：abs(b)=0.3736、S0=30.5∠-4.8° 时 arg b 从 265° 变到 280° 只动镜面 **0.4-0.5 dB**（因 400·abs(b)≫abs(S0)），但近瓣结构会变。相位真正的价值是**唯一携带 224°/137° 信息的量**（265°≈(φ0+φ1)/2+180°，后续工作计划.md:180）。冻结相位＝固化标定误差，并丢掉 A1 唯一的判别信号。

**6.4 与 P1/A6/M4 冲突。** 带内 b(f) 变化 8.6 dB ⇒ 常数 b 只在 10 GHz 成立，A6 五频点/跨频推理立刻失效；P1 要"按 224° 重调 r1 把阵中相位差拉回 180°"（后续工作计划.md:334），重调后 b 必须重学。D3 自己的回滚判据（spec_err>0.3 dB）只测均值，测不出"均值不变、散布变大"——应按 6.1 的 ±14° 相位摆动同时看 std(spec_err)。

**6.5 最小执行。** 先加 model.freeze_b（M8 的 schema），冻结时用 nn.Parameter(2)；**同时**把 mean(bit) 作为标量喂进全局支路；三路同 split 对比：per-sample MLP / 常数 / mean(bit)+线性。判据：spec_err 的**均值与标准差**、60-90° 分带 rmse 均不劣化 ≤0.1 dB，才允许删 MLP。

## 7 跨项冲突与建议顺序

- **一个自由度被三处抢**：224°（库相位）、b（均匀复偏移）、M1（对比偏移）。前两者是同一个数（abs(DC)=abs(Γ)abs(cos(Δφ/2))，+10.81 vs 实测 +10.80），只能留一个；M1 是另一个自由度（对比），只值 +0.3 dB。
- **口径未定**：abs(Γ)=1.002（theory，标量倾角）vs 0.90（代码 vector 口径反演）差 0.5 dB；先定口径再做 A2。
- 建议顺序（与建议文档不同）：① 0 CST：单参数 g 扫描 + 224°/137° 两个库的 M0 直接评估（1.6），它决定 M1/A1/A2 还要不要做；② A1 重写为 2x2 + 混合环境，只取 Δφ_eff 与 ε；③ A4（零成本），A3 并入 4 参数化（若 ε 可观）；④ A5 改 θ 外推判别 + CST 单元方向图；⑤ M5 降级为 per-f 核缓存，随 M4/A6 做。
- 反对"先别碰 GNN 结构"的**理由**：b 常数化的根因是 mean-pool 看不见占空比，那正是结构问题（1 个标量输入），不是"图没用"。
