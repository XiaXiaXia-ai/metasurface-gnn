### 3.5 B2：`area_mm2`

- **`area_mm2=None` 与改动前逐位一致：是。**
  - numpy：`c = const_c(...) * scale`（`:128`）与旧表达式 `const_c(...) * scale * s` 左结合顺序相同 → 同一浮点序列；
  - torch：`self.c = const_c(...) * self.scale`（`:186`）不变，`:191` 的 `if self.area is not None` 不进入 → `__call__` 旧路径；
  - `fields_numpy` 多传 `area_mm2=None`（`:279`）→ 同一分支。
- **`area=P²` 是否等价**：数学等价；**float64 下相对差 ~1e-16**；**float32（默认 `runtime.dtype`）下 torch 路径约 1e-6**
  ——因为新实现"先把 q 乘 A 再求和"，旧实现"先求和再乘 A"，N=400 次累加的舍入不同。因此"1e-15 级差别"**只对 float64 成立**，
  文档/测试若写成 1e-15 会在 float32 下失败。
- **标量 `area_mm2` 会崩**：`self.area = torch.as_tensor(np.asarray(196.0)) ` 是 **0 维**，`self.area.shape[0]`（`:192`）抛
  `IndexError: tuple index out of range`。而 numpy 路径 `q * np.asarray(196.0)` 是合法广播 → 两条路径 API 不一致。
  "给定 `area=P²`"的最自然写法（传标量）在 torch 侧**无法使用**。
- **签名位置**：`farfield_numpy(..., n_side=None, area_mm2=None)`（`:110-114`）与
  `FarFieldOperator.__init__(..., n_side=20, area_mm2=None)`（`:161-166`）都加在**末尾**；全库调用点都给 ≤7 个位置参数
  或全关键字（`tests/test_radiation.py:33,57,119,148`；`tests/test_graph.py:103,107,130,149,164`；`experiment.py:149`）
  → **不会错位**。
- **`fields_numpy` 关键字传参与签名一致**：位置实参依次是 q, theta, phi, freq, period, pos_np, projection, scale（第 8 个 = `scale`），
  再接 `area_mm2=` 关键字 → **一致**（`:277-279` 对 `:110-114`）。
- **`self.area` 未注册 buffer、`to()` 不搬它**：但 `__call__` 每次都 `self.area.to(dtype=q_re.dtype, device=q_re.device)`（`:246`）
  → 结果正确，代价是每次 forward 一次小拷贝（可忽略）。

### 阻断（1）

**Z1｜`_remove_graph_mean` 在 B=1 时不做去均值**

- **file:line**：`gnn/msgnn/models/pipeline.py:33-34`（早退）、`:78-80`（调用点）。
- **依据**：声称是"在 M3 分支对 Δq 做 **per-graph** 去均值，使全局支路 b 唯一承担均匀分量"；单图 batch 的均值完全良定义，
  没有任何理由跳过。跳过导致：`predict.py:45`（单样本）、`smoke_test.py:59`（单样本）、`inference.py:18-20` 与
  `train.py:105-107` 的尾批（可能 1 个样本）走**不同函数**→ 同一样本预测随 batch 组成变化；`predict.py:80-83` 的
  `mean(dq)` 诊断在单样本下失效；REPORT 的"mean(Δq)≈0"验收永远无法在单样本路径上成立。
  另外 `residual_gnn._pool`(`residual_gnn.py:66-70`) 用 `bincount(minlength=n_graphs)` 处理 B=1 是正常路径，说明本仓库并不把 B=1 当特例。
- **最小修法**：把条件改成 `if graph_index is None: return v_re, v_im`（删掉 `or n_graphs <= 1`）；`n_graphs` 只用于分配 buffer。
  加一个测试：同一张图 `collate([g])` 与 `collate([g, g2, g3])` 中 g 的 `sig_db` 逐点一致（float64，1e-12）。
  **不会破坏现有测试**：`test_permutation_equivariance_full_model`(`tests/test_graph.py:117-157`) 是 B=1，且 centering 对节点置换等变，
  两侧同变 → 断言不受影响。

### 重要（5）

**Z2｜`max_samples` 截断污染快照与切分**

- **file:line**：`gnn/msgnn/data/dataset.py:268-271`（截断）、`:283`（`build_snapshot` 复用同一函数）、
  `gnn/msgnn/experiment.py:106,117`（build_context 建快照/扫快照）、`:121-135`（split 与落盘）。
- **依据**：`build_context` 在无快照时用**同一个 cfg** 调 `build_snapshot` → `scan_cases` 已按 `max_samples` 截断 →
  `snapshot.json` 的 `n` 与 `files` 只剩 k 条，与 `config.py:38` 的注释"0 = every sample in the snapshot"及本轮注释
  "so a run can be capped **without touching the snapshot**"**直接矛盾**。且截断发生在 `make_splits`(`experiment.py:124`) 之前 →
  capped run 的 val/test 是对截断子集重新划分（不是全量 split 的子集），`experiment.py:135` 还会用截断集**覆盖**
  `out_dir/splits.json`；同一 run 目录下次以 `max_samples=0` 启动时，`build_context:121-122` 直接吃进 k 例的 splits →
  静默变成小样本 run。默认 `max_samples=0` 时不触发。
- **最小修法**：截断移出 `scan_cases`，放到 `build_context`（与 `max_cases` 并列、在 split 之后、只裁 `cases`）；
  或 `build_snapshot` 里用 `dataclasses.replace(cfg, max_samples=0)`。加测试：`max_samples=k` 时 `snapshot["n"]` 与无截断一致。

**Z3｜标量 `area_mm2` 在 torch 路径 IndexError**

- **file:line**：`gnn/msgnn/physics/radiation.py:189-194`（`self.area.shape[0]`）。
- **依据**：`np.asarray(196.0)` 是 0 维数组，`torch.as_tensor(...)` 是 0 维张量，`shape[0]` 抛 `IndexError`；
  同一参数在 `farfield_numpy`(`:130`) 却能广播。docstring(`:123`) 写"Passing A_n = P^2 reproduces the uniform path bit for bit"，
  而最自然的 `A=P**2` 标量写法在 torch 侧**直接崩**。
- **最小修法**：统一归一为 1 维：`a = np.asarray(area_mm2, dtype=float).reshape(-1)`；`a.size == 1` 时 `a = np.full(self.n, a[0])`，
