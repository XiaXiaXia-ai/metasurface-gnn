## 0 结论先行

| 问题 | 答案 |
|---|---|
| 13.82 dB 缺口是什么？ | 一个**与编码无关、空间均匀、与编码项正交**的相干分量：b = 0.366 ∠ −95°（相对编码项），等效为「每个单元多了一份 0.37 的正交权重」 |
| 三个候选谁负责？ | **H2 的加性形式胜出，但 H2 的几何版本（贴片间介质面按 Γ_gap 反射）被定量排除**；其相位把物理来源指向 **H1 的微观机制（互耦的平均场 / 共同模）**。H3 被对称性与量级双重排除 |
| 证据 | ① 幅度：几何 H2 预测 15.80 dBsm，实测 10.80（高 5.0 dB）② 相位：几何 H2 的背景相位 142°，实测最优点 265°（正交）③ 谱形：ψ=265° 时 RMSE 1.78 dB、相关 0.96/0.92/0.92；ψ=142° 时 RMSE 3.28、相关 0.82/0.80/0.70；纯 H1 相位压缩 RMSE 3.22、相关 0.67 |
| 弥散为什么算得准？ | 弥散均值反演出 **in-array 振幅 = 1.002**（Floquet 给 0.867）。Floquet 的 −1.24 dB **不是物理损耗**（无损基板传输线模型给 −0.0007 dB），是数值损耗。修正后 M0 的弥散 −6.64 vs 实测 −6.62（差 0.02 dB） |
| 若把 180° 在阵中补正，镜面能到多少？ | **−2.60 dBsm，缩减 21.94 dB**（比现在的 8.54 dB 再好 13.4 dB）。若同时换成严格平衡码，可到 −29 dBsm 量级 |
| 8.54 dB 是算法可补偿还是几何决定？ | **不是编码可补偿的**：换平衡码只值 0.9 dB 甚至更差。它是**工作点/有效相位差的系统性偏移**，只能靠改单元或改工作频率（把阵中 180° 交点从 9.60 GHz 拉回 10 GHz）拿回 |

一句话：**镜面缺口 = 阵中 1-bit 相位差被压到约 137°（而非孤立单元的 180°）所产生的共同模**；它的频率色散是一条 f0 = 9.60 GHz、Q = 4.86 的单一谐振曲线，把整个 8.60 dB 的带内变化拟合到 0.15 dB 以内。

### 1.2 五个度量（common.metrics，所有模型 / 所有数据同一套定义）

- **specular_dbsm**：θ=0 处总 σ；
- **mean_far_dbsm**：θ∈[10°,90°] 全 φ 的**线性**平均再取 dB；
- **corr_phiX**：φ=X 子午线上 θ∈[6°,60°]、实测 > −30 dB 的样本，模型与实测 dB 值的 Pearson 相关（2° 网格无 φ=45°，取最近子午线 φ=44°，代码中已注明）；
- **rmse_6_60deg**：θ∈[6°,60°] 全 φ、实测 > −30 dB 上的 dB 均方根误差；
- **runtime_s**：单次模型求值（不含拟合）。

### 1.3 统一归一化（每个模型的自检基准）

标量口径下（本文主口径）

    sqrt(sigma)(θ,φ) = (2 sqrt(pi) / λ) · P(θ,φ) · Σ_n w_n exp[j k (x_m u + y_n v)]
    u = sinθ cosφ,  v = sinθ sinφ

其中 P_θ = cosθ（标量口径）或 P_θ = cosθ cosφ、P_φ = −sinφ（矢量口径）。w_n ≡ 1 时

    sigma(0) = 4 pi A² / λ² = 85.94 m² = 19.342 dBsm

**这是所有模型的必过自检**（§3）。cosθ 是等效电流/口径的倾斜因子，不是单元方向图——这一点在 §2.2 的 M1 里单独检验。

### 2.1 M0：阵列因子（基线）

    sqrt(sigma) = (2 sqrt(pi)/λ) · cosθ · A_cell · Σ_n Γ_bit(n) exp[j k (x_m u + y_n v)]

- 假设：单元 = 点源；单元间无耦合、无边缘、无单元口径因子；Γ 取**孤立周期单元**的 Floquet 结果；
- A_cell = P² = 196 mm² 就是「一个点所代表的面积」，因此全 1 时自动给出 19.342；
- 复现了原诊断脚本的全部数字：镜面 **−3.01**（原文 −3.02）、弥散 **−7.95**、相关 **0.83/0.85/0.78**。

### 2.2 M1 / M1b：加单元方向图

M1：sqrt(sigma) → scale · cos^q θ · sqrt(sigma_M0)，在 θ∈[6,60] 的 dB 域做线性最小二乘（对 log10(scale) 与 q 是线性的）。拟合结果 **q = −0.396，scale = 1.112**（单元方向图比 cosθ 更宽）。

M1b：用真实圆盘的 Airy 方向图 f_e = 2 J1(k r sinθ)/(k r sinθ)（r = 4.7 mm，第一零点在 sinθ = 1.22λ/2r = 3.9，可见区内无零点，几乎各向同性），只拟合一个幅度 → **scale = 1.27**。

**结构性结论**：f_e(0) = 1 对任何 q 成立，所以**单元方向图在 θ=0 处恒等于 1，原理上无法填补镜面缺口**。M1/M1b 只能改弥散：把弥散从 −7.95 拉到 −6.60 / −6.07（实测 −6.62），但镜面仍差 **12.9 / 11.7 dB**。这是一条负结果，也是排除「单元方向图 / 口径效率」这一类的硬证据。

### 2.3 M2：物理光学（H2 天然进入）

面电流 J = 2 n̂ × (n̂ × E_refl)/Z0，贴片上 E_refl = Γ_bit E_inc，贴片间介质上 E_refl = Γ_gap E_inc：

    sqrt(sigma) = (2 sqrt(pi)/λ) cosθ Σ_n {
        Γ_bit A_p airy(r_bit, θ)
      + Γ_gap [ P² sinc(kPu/2) sinc(kPv/2) − A_p airy(r_bit, θ) ] } exp(j k R_n · r̂)

其中 airy(r) = 2 J1(k r sinθ)/(k r sinθ) 是圆盘的**精确**积分，方括号内是「方格减圆盘」的**精确**间隙积分（两者都以单元中心为相位原点，可因子化）。全 1 时两项相加严格等于 P² sinc·sinc，θ=0 处给出 19.342（自检通过）；且已数值验证：当全部单元同态且 Γ_gap = Γ_bit 时，M2 与 M3 **逐点相同（max|Δ| = 0.0000 dB）**。

Γ_gap 的物理锚点由 M5 的传输线给出：Z_in = j Z_d tan(k_d h)，Γ_gap = 1.000∠141.9°（10 GHz，tanδ = 0.0013）。

### 2.4 M3：Rayleigh–Sommerfeld（LPR 式 4）

    E(x,y,z) = ∬ (z/l²)(1/(2πl) + 1/(jλ)) exp(−j2πl/λ) E(x',y',0) dx'dy'
    l = sqrt((x−x')² + (y−y')² + z²)

- 口径取**分段常值**（每 14 mm 方格一个 Γ），因为式 (4) 积的是连续场，点采样不合法；
- 方格的积分是解析的：∫_cell exp(j k r̂·r') dS' = P² sinc(kPu/2) sinc(kPv/2) exp(j k R_n·r̂)，故 z→∞ 极限下 M3 = M0 ×（有限单元口径因子）；
- 有限距离：直接在 φ=0 半平面 (z tanθ, 0, z) 上做 O(N_ap·N_obs) 空间求和（1 mm 采样，281² = 78961 个口径点），不做任何近轴近似；
- **数值验证**：式 (4) 的第二项 1/(2πl) 与第一项之比为 O(1/l)，在 20λ/30λ 上对场的影响 **< 0.004 dB**（nearfield.csv），可忽略；
- 自检：全 1 时 19.342。

### 2.5 M4：角谱 / 平面波展开（LPR 式 5）

FFT 传递函数 H = exp(j k_z z)，k_z = sqrt(k0² − kx² − ky²)，倏逝波取 k_z = j sqrt(kx² + ky² − k0²) 并按其衰减（与「直接丢弃」在 z ≥ 1λ 时差 < 1e−6 dB）。远场用

    E(r,θ,φ) = j k exp(−jkr)/(2πr) · [ θ̂ (f_x cosφ + f_y sinφ) + φ̂ cosθ (−f_x sinφ + f_y cosφ) ]

- **交叉验证（关键）**：与 M3 在**同一倾斜因子口径**下逐点比对，θ ≤ 60°、场强 > −20 dB 的 19848 个样本上 **max|Δ| = 0.051 dB，corr = 0.999998** → 远区一致性优于 0.1 dB，两个数值路线互证通过；
- **论文式 (5) 原文没有 θ 分量的倾斜因子**，与 RS 结果在 6–60° 上 rms 差 **1.77 dB**（大角偏大）。表里同时给出 M4_AS_paper（原文）与 M4c_AS_cos（补 cosθ，等价于 M3）两行，便于看清这一点；
- 自检：全 1 时 19.342（两种口径在 θ=0 相同）。

### 2.6 M6：耦合 / 相位压缩（H1）

    Γ_n = |Γ| exp(j α φ_bit),     |a| = |Γ| cos(α·180°/2)

只改相位、不改 |Γ_n|，因此 Σ|Γ_n|² 不变、**弥散电平对 α 不敏感**——这正是把 H1 与 H2 区分开的物理要害。α = 1 退化为 M0。

M6b 是更第一性的一阶互耦（DDA）：a_n = Γ_n + c Σ_m W_nm a_m，W_nm = (P/r_nm) exp(−j k r_nm)（半径 3 个单元，24 个邻居），(I − cW) a = Γ 精确解。用复数 c 对（镜面, 弥散）二目标做最小二乘 → **c = −0.589 + 0.169j（|c| = 0.61，arg 164°）**，镜面 10.28、弥散 −5.21（残差 0.52 / 1.41 dB），但**方向图被破坏**：corr 0.26/0.31/0.66、RMSE 6.44 dB。→ 短程互耦能凑出两个标量，却凑不出谱形。

### 2.7 M5：单元等效电路（加分项，不出方向图）

- 接地介质板传输线（**无任何拟合**）：|Γ_gap| = 0.9999，即 **−0.0007 dB**；相位 141.9° @ 10 GHz，带内从 143.6°（9.6 GHz）变到 140.2°（10.4 GHz）。
- **由此判定**：Floquet 给的 |S11| = −1.24 / −1.39 dB（|Γ| = 0.867 / 0.852）**不可能是物理损耗**——真要做成 1.24 dB 的损耗，需要 tanδ_eff ≈ 0.14，是数据表值 0.0013 的 100 倍。它是 Floquet 口/网格的数值损耗。§5.2 用弥散电平独立把 in-array 振幅定到 **1.002**，与此一致。
- 贴片并联 LC 模型（TM11 谐振 + 圆盘电容）：r = 2.0 mm 给 176.4°（实测 174.6°，差 1.8°），r = 4.7 mm 给 169.7°（实测 −5.3°，差 175°）。说明**简单 LC 不能替代 Floquet 单元数据**——大贴片已进入谐振区，准静态模型失效。但它对 |Γ| ≈ 1 的判断是可靠的。

五条读数：

1. **相关在本数据上已经饱和，不是判别量**。AF 家族在 6–60° 全 φ 上一律 0.92–0.93，彼此差 ≤ 0.01；真正的差别在**残差电平**（RMSE 2.41 vs 3.94 dB）与**分带结构**。用 r 排序会把 M1 与 M3 判成平手，而它们的 RMSE 差 1.5 dB。
2. **core（0–5°，镜面瓣）上所有正向模型的 r ≈ 0**（−0.01）。这不是负相关，而是**零技巧**：模型在该区给 −3 dBsm 量级的散斑，实测是一个 10.8 dBsm 的平台，两者起伏互不相关。只有把均匀分量显式塞进去的 M2（0.66–0.71）与 M6b（0.45）在这里才有技巧——这正是 13.8 dB 缺口在相关域的体现。
3. **M2 是"用 core 换 near/mid"**：core 0.66–0.71（家族最好），但 near 掉到 0.30、mid 0.56–0.67（AF 家族为 0.67 / 0.91）。这就是 §5.3「几何 H2 要么补镜面、要么保弥散」在相关域的版本。
4. **far（60–90°）暴露倾斜因子**：M0b 矢量投影 0.51、M4c 0.37、M4 原文 0.20。大角区几乎无人可用——实测在 60–90° 仍有 −20…−30 dBsm，而 cosθ 类模型已掉到 −40 以下。这与 M1 拟合出的 q = −0.40（单元方向图比 cosθ 更宽）是同一件事的弱形式。
5. **2D 相关（0.93）高于 φ=0 切线（0.83）**：子午线切线正好穿过零深与散斑节点，是比 2D 平均**更严格**的检验；反之 2D 平均被大量"中规中矩"的样本稀释，容易给出虚高的乐观数字。主表仍以切线相关 + RMSE 为准，2D 相关作为补充。

## 5 归因：13.82 dB 到底是什么

### 5.1 缺口的第一性事实

把实测镜面折算成「口径归一化振幅」（以 PEC 板为 1）：

    |a| = sqrt(sigma_meas) / sqrt(sigma_plate) = 10^((10.798 − 19.342)/20) = 0.3740

**这个 0.374 是全部推理的锚点**，它与编码几乎无关（两个随机码 10.798 / 10.974，差 0.176 dB；两者 1 的个数都是 46/100，一阶和完全相同）。

角向形状进一步锁定它的性质：镜面瓣在 φ=0 上 10.80(0°)、11.44(1°)、11.29(2°)、10.31(3°)、8.42(4°)，−3 dB 宽度约 6°——**与 280 mm 全口径的衍射极限（5.4°）同量级**。所以它是一个**铺满整个口径、同相的均匀分量**，不是边缘 / 局部效应。

> 顺带修正原诊断的一个说法：「与编码无关」这一结论只被两个**同占空比**的码支持（46/46），因此它比原文的表述要弱一些。真正与编码无关的证据来自 §5.6 的色散。

### 5.2 弥散不变式：in-array 振幅 = 1.002，Floquet 的 −1.24 dB 是假的

弥散均值由 Σ|w_n|² 决定（与相位分布几乎无关）。用 M0 扫描单一振幅因子 g：

| g | 弥散 (dBsm) |
|---|---|
| 0.867（Floquet） | −7.95 |
| 1.000 | −6.64 |
| **1.002（反演值）** | **−6.617 ≡ 实测** |

即 **in-array 有效振幅 = 1.002 ± 0.01**，比 Floquet 的 0.867 高 1.33 dB。结合 M5 的传输线结论（无损基板应给 −0.0007 dB），可判定：**Floquet 的 −1.24 dB 是数值损耗，阵中真实的反射振幅约等于 1**。这条修正把 M0 的弥散误差从 1.33 dB 压到 **0.02 dB**，是全部模型里最干净的一次对账。

### 5.3 H2（几何版）：幅度和相位都错

**幅度**：几何 H2 的含义是「贴片间 78% 的面积按 Γ_gap 反射、贴片 22% 按 Γ_bit」。取物理值 Γ_gap = 1.000∠141.9°，M2 给出 **15.80 dBsm**（实测 10.80）——**高 5.0 dB**。也就是说，「裸露基板全反射」的背景**太强了**，不是太弱。要让镜面回到 10.80，必须把 |Γ_gap| 压到 **0.628**；但此时两个 bit 的权重被一起拉小、编码对比度下降，**弥散塌到 −16.96（差 10.3 dB）**。

二维扫描（hypotheses_h2geo_scan.csv，|Γ_gap| ∈ [0.2, 1.45] × 相位 0..350°）：

| | \|Γ_gap\| | 相位 | 镜面 | 弥散 | 联合残差 |
|---|---|---|---|---|---|
| 物理锚点（TL） | 1.000 | 141.9° | 15.80 | −14.14 | 12.53 |
| 最优联合 | 0.65 | 190° | 10.77 | −16.48 | **9.90** |

**几何 H2 的联合残差下不到 9.9 dB**：它无法同时给出 10.80 的镜面和 −6.62 的弥散。这是一条硬排除。

**相位**：把「加性背景」写成 B = β exp(jψ)（Floquet 振幅 + 均匀背景），强制镜面 = 10.80，扫 ψ（hypotheses_h2.csv，Floquet 振幅 0.86）：

| ψ | β | 镜面 | 弥散 | corr φ0/45/90 | RMSE |
|---|---|---|---|---|---|
| 142°（基板物理值） | 0.437 | 10.80 | −6.49 | 0.82 / 0.80 / 0.70 | **3.28** |
| 265°（最优） | 0.366 | 10.80 | −6.50 | **0.96 / 0.92 / 0.92** | **1.78** |
| 0° | 0.298 | 10.80 | −7.79 | 0.88 / 0.83 / 0.66 | 3.17 |
| 180° | 0.450 | 10.80 | −7.78 | 0.89 / 0.83 / 0.79 | 3.48 |

基板相位（142°，相对编码项 −33°）给出的 RMSE 是 3.28 dB，**和 M0（3.05）一样差**；而 265° 给出 1.78 dB、相关 0.96/0.92/0.92——比 M0 提升一大截。

**265° 意味着什么？** 编码项（两态之差）在 Floquet 系里位于 174.65°，而 265° − 174.65° = **+90°：背景与编码项正交**。一阶相位压缩产生的共同模正好在差模的 ±90° 上（Γ0+Γ1 ∝ cos(Δφ/2) 与 Γ1−Γ0 ∝ j sin(Δφ/2) 正交）。所以**谱形把物理来源指回 H1 的微观机制（互耦的平均场），而否定 H2 的几何版本（基板反射应与编码项近同相或反相，而不是正交）**。

### 5.4 H1（纯相位压缩）：能对上标量，对不上谱形

两种写法都试过（hypotheses.csv）：

| 写法 | 参数 | 镜面 | 弥散 | corr φ0/45/90 | RMSE |
|---|---|---|---|---|---|
| 单参数（\|Γ\| 由弥散钉死） | Δφ = 137.5°, \|Γ\| = 1.002 | 10.73 | −7.10 | 0.67 / 0.69 / 0.69 | 3.34 |
| 双参数（镜面 + 弥散同时命中） | Δφ = 139.4°, \|Γ\| = 1.054 | 10.80 | −6.62 | 0.68 / 0.67 / 0.69 | 3.22 |

- Δφ = 137° 与 §5.1 的 0.374 自洽：|a| = cos(137°/2) = 0.374 ✓；
- 但**纯相位压缩会改变两态的对比度**，从而把谱形一起改掉：corr 从 M0 的 0.83 掉到 0.67，RMSE 从 3.05 升到 3.22。要同时命中弥散，必须把 |Γ| 抬到 **1.054**（比理想反射体高 5%）；
- 也就是说：**H1 作为「全局相位压缩」是一个可行的等效描述（Δφ_eff ≈ 137°），但精度不如「正交加性背景」**（RMSE 3.22 vs 1.78）。二者在物理上是同一件事的两端：耦合的平均场。

> 真正的判别落在「背景与编码项的相对相位」上，而不是幅度上。幅度只能定出 |a| = 0.374（或 |Γ| cos(Δφ/2) 的乘积），是退化的；相位把 H1 机制与 H2 几何分开。

### 5.5 H3（边缘 / 地板）：对称性 + 量级，双重排除

x 极化正入射下，地板边缘的 PO 电流 J = 2 n̂ × H_inc：只有法向为 ±x 的两条边有电流（J = ∓2E0/Z0 ẑ），±y 两条边 n̂ × H ≡ 0。两条 ±x 边是**反平行、相距 280 mm** 的纵电流，其远场

    sqrt(sigma_rim) = (2 sqrt(pi)/λ) · sinθ · |2j sin(k·140·u) · I_y · I_z|

**在 θ=0 处严格为零**（sinθ = 0 且 sin(140ku) = 0），峰值出现在 **θ = 54°**、只有 **−21.97 dBsm**：

- 方向错：H3 在镜面方向恒等于 0，不可能造出 6° 宽的镜面尖峰；
- 量级错：峰值比实测镜面低 **32.8 dB**；
- 另有一条独立反证：θ = 180° 的瓣是 19.376 dBsm、−3 dB 半宽 3°，与 280 mm PEC 板的 19.342 dBsm 差 0.03 dB——它**正好验证了 dBsm 标定与 1° 角采样**，同时说明「地板背面」这个机制只在 θ ≈ 180°，不在 θ ≈ 0。

### 5.6 色散：一条谐振曲线吃掉 8.6 dB

把 5 个频点的镜面都折算成 |a|(f)，再按 |a| = |Γ| cos(Δφ/2) 反演 Δφ_eff(f)：

| f (GHz) | \|a\| | Δφ_eff (°) | 实测镜面 | 拟合镜面 |
|---|---|---|---|---|
| 9.8 | 0.2007 | 156.8 | 5.219 | 5.085 |
| 9.9 | 0.2859 | 146.8 | 8.378 | 8.501 |
| 10.0 | 0.3740 | 136.1 | 10.798 | 10.818 |
| 10.1 | 0.4526 | 126.2 | 12.543 | 12.516 |
| 10.2 | 0.5194 | 117.4 | 13.823 | 13.815 |

用单谐振相位差曲线 Δφ(f) = 180° − 2 arctan(2Q(f − f0)/f0) 拟合两个参数：

    f0 = 9.601 GHz,  Q = 4.86,  5 点最大残差 0.15 dB

- **整个 8.60 dB 的带内变化 = 一条谐振曲线 + 2 个参数**；
- Q = 4.9 与「180° 相位范围的 1-bit 单元」应有的 Q（经验值约为 4）一致，不是拟合出来的巧合；
- 物理解读：**阵中的 180° 交点被拉到 9.60 GHz，而孤立单元（Floquet）是 10.00 GHz**——工作点向低频偏了 0.40 GHz（−4%）。这与既有判断（「工作点整体向低频偏移」）方向一致，并给出了定量值。

### 5.7 归因结论与残差

| 候选 | 机制 | 定量判据 | 判决 |
|---|---|---|---|
| **H1** | 阵中相位压缩 / 互耦平均场 | 需要 Δφ_eff = 137 ± 3°（0.374 = cos(Δφ/2)）；色散给出 f0 = 9.60 GHz、Q = 4.86（残差 0.15 dB）；背景相位应为正交（+90°），实测最优 265° = 174.65 + 90 ✓ | **成立**（作为等效描述），2 参数下 RMSE 3.22 |
| **H2** | 未调制相干背景（贴片间介质） | 几何版预测 15.80 dBsm（高 5.0 dB）；重标定后弥散差 10.3 dB（联合残差 9.9 dB）；相位 142° 给出 RMSE 3.28 | 几何版**排除**；但其**加性形式**（正交相位、b = 0.366）是最优描述（RMSE 1.78） |
| **H3** | 边缘 / 地板镜面 | θ=0 处严格为 0；峰值 −21.97 dBsm，低 32.8 dB；θ=180 的 19.38 dBsm 是地板背面，位置不对 | **排除** |

**最终表述**：

> 13.82 dB 的缺口是一个**与编码无关、铺满口径、与编码项正交的均匀相干分量**，幅度 0.366–0.374（以 PEC 板为 1）。
> 它的**相位**（正交）排除了「贴片间介质按统一相位反射」的几何解释，指向**互耦 / 局部周期性误差造成的 1-bit 相位压缩（共同模）**：阵中两态相位差约 **137°**，而孤立单元是 179.95°。
> 它的**频率色散**（f0 = 9.60 GHz、Q = 4.86）进一步说明这是**整个阵的工作点相对孤立单元下移 0.4 GHz**，而不是随机误差。
> **残差**：最优描述（正交加性背景，1 个自由参数 b 由镜面定、1 个相位由谱形定）在 10 GHz 上给出镜面 10.80、弥散 −6.50、相关 0.96/0.92/0.92、RMSE **1.78 dB**；纯 H1（2 参数）给 RMSE 3.22 dB；M0 给 3.05 dB。

## 6 「可达最好缩减」：8.54 dB 是算法能补的吗？

fit_hypotheses.achievable() 的结果（10 GHz，以 19.342 dBsm 为基准）：

| 情形 | 镜面 (dBsm) | 缩减 (dB) | 说明 |
|---|---|---|---|
| A 现编码 + 理想 180° 对 + **无背景** | **−2.60** | **21.94** | 把 137° 补回 180° 的理论上限（编码不平衡只贡献 0.08 振幅） |
| B 现编码 + 180° 对 + 背景 b = 0.44 保留 | 10.80 | 8.54 | 现状：背景完全主导 |
| C 平衡码（50/50）+ 理想 180° + 无背景 | −41.8 | 61.2 | 精确抵消（实际受残余相位误差限制） |
| D 平衡码 + 背景保留 | 12.19 | 7.16 | **换码不管用**，甚至更差（背景与残余不平衡同相） |
| E 平衡码 + 10° rms 随机相位误差 | −29.3 | 48.6 | 现实下限 |

**结论**：

1. **8.54 dB 不是编码能补的**：把 46/54 的不平衡换成严格 50/50（C/D 行）只值 0.9 dB，甚至因为背景与残余不平衡同相而变差；
2. **能不能补，取决于 0.37 那份背景是不是「可去掉的」**：
   - 若它来自**阵中相位压缩**（H1，本质是局部周期性误差 / 工作点偏移）→ 把阵中 180° 交点调回 10 GHz（改基板厚度、改贴片半径，或直接把工作频率移到 9.6 GHz）就能去掉，镜面落到 **−2.60 dBsm，缩减 21.9 dB**（+13.4 dB 的净收益）；
   - 若它来自**真正不可调的几何背景**（H2 几何版）→ 一点也拿不回来，必须改单元几何（提高贴片覆盖率）；
3. 由于 §5.3–5.6 的证据（相位正交 + 谐振色散）都指向 H1 一侧，**建议按 H1 处理**：先做一次「混合环境超胞 Floquet」（随机码包围的中心单元）确认阵中 Γ，再把工作点调回 10 GHz。这是**不需要改 1000 例数据集**的最小改动路径。

## 7 对「物理算子 + GNN 学阵中权重」路线的启示

1. **算子选 M0 + 正交背景最划算**。理由：M0 的镜面 / 弥散误差分别是 13.8 / 1.3 dB，但**去掉均匀分量后，M0 的谱形相关已有 0.83**；把均匀分量作为 1 个复数全局参数（每样本 2 个实数）加进去，相关升到 0.96、RMSE 降到 1.78。GNN 只需学**每单元相对该全局分量的偏差**，自由度从 400 个复数降到「1 个复数 + 小残差」，数据效率最高。
2. **不要用 M3/M4 的点采样差异去拟合**：M3/M4 与 M0 的差别只是有限单元口径因子（弥散 −0.55 dB），属于**系统偏差**，应作为固定算子的一部分，不该交给网络学。
3. **需要的额外数据 / 参数**（按优先级）：
   - **混合环境超胞 Floquet**（随机码包围的中心单元，3×3 或 5×5 超胞）：直接给出阵中 Γ，把 137° vs 180° **独立证实**，并给 GNN 一个物理上正确的初值；
   - **复数远场标签**（现在 dataset 只存幅度）：相位是分离 H1/H2 的唯一手段（§5.3），也是复域监督的前提；
   - **近场切片**（20λ/30λ）：M3/M4 已证明近场到远场的一致性 < 0.1 dB，近场监督能把「传播」和「局部权重」彻底解耦（LPR 的做法）；
   - **占空比分层的结构化码本**：现在 1000 例都是 46% 左右的 i.i.d. 码，镜面标签方差只有 0.2 dB，学不到东西（§6 的 C/D 行说明换码本身收益极小）。
4. **算子实现建议**：common.aperture_sum 的两级可分离求和把 400 单元 × 65160 角点压到 2.6M 次复指数（0.07 s/样本，CPU），完全够做在线数据增强；M4 的 FFT 路线只在需要 uv 图或近场时用（3 s/样本）。

## 9 不确定度与已知局限

1. **θ=0 的绝对相位不可用**：CST 导出的远场相位含 exp(−jkR) 参考项（实测镜面相位的频率斜率 −860°/GHz，对应 R ≈ 0.67 m），无法与模型的绝对相位对齐。因此本文只用**相对相位**（背景 vs 编码项）做判别，不依赖绝对相位。
2. **两个随机码同占空比（46/100）**，镜面的「编码无关性」证据偏弱；真正强的是色散（§5.6）。要彻底闭合，需要一个不同占空比的码（例如 30/70 或棋盘码）。
3. **M2 的「贴片区 × Γ(bit)」是任务给定的粗模型**：物理上贴片区应按局部 PEC/谐振响应而非单元整体 Γ 加权，因此 M2 的绝对电平有系统不确定性；但「几何 H2 高 5 dB + 相位 142° 谱形差」这两条结论对该细节不敏感（|Γ_gap| 扫到 1.45 也翻不过来）。
4. **贴片区局部 Γ 的独立模型（原计划的 M7）未单独建**：它的作用与 M2 的 coverage_scale 参数等价，已由 M2 的扫描覆盖。
5. **近场 RS vs AS 的 0.23 / 0.58 dB 差异**源于式 (4) 的倾斜因子与精确 Helmholtz 解的固有差别，不是代码错误（远区一致性 0.051 dB 已验证）。
