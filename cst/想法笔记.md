### 0001 · 2026-10-23 · 三个方向性想法：可变阵列规模 / 多频段 / 异形单元混排

**原话**：

> 可变的阵列规模、多频段、异形单元混排

**原意（我的理解，`待确认`）**

1. **可变的阵列规模**：同一套模型能处理不同阵元数/口径（$N\times M$ 不固定、阵元间距或形状可变），而不是每种规模各训一个专用网络。
2. **多频段**：从当前单频点（10 GHz 口径、阵中 180° 交点已偏到 9.6 GHz）扩展到多频点或宽带，模型需显式接收频率/波长条件。
3. **异形单元混排**：同一孔径内混用不同几何的单元（不同相位覆盖、不同色散、不同插损），而非现有 2×2 宏单元或逐单元 1-bit 的二选一。

**备注**

- 三者的共同指向是**泛化性/通用性**：让「物理主干 + 全局隐变量 + 学每单元修正」这条路线不绑定在某一固定阵列、某一频点、某一种单元上。可视为论文层面的"通用框架"叙事，与「把单个 case 做深」的现有计划是两条不同的验收标准，`待确认` 优先级。
- 与现状的张力（记录，不裁决）：
  - 现有数据集是 **20×20=400、单频 10 GHz、逐单元 1-bit**；可变规模会牵动远场聚合方式、训练/验证集划分（按规模留出？）与位置编码是否随规模失效。
  - 多频段先要过**色散关**：单元相位随频率变化，同一码在不同频点给出不同方向图；且 §3.4 已证明阵中存在与编码无关的相干残留，换频点时该残留的相位/幅度也需重标定。
  - 异形混排等于引入**第三类自由度**，会打破现有"宏单元(100 bit) vs 逐单元 1-bit(400 bit)"的 BLOCK 对照设计，需重新定义可比重叠的对照组。
- `待确认`：
  1. 可变规模是**训练时随机规模**（size-agnostic 训练），还是**固定规模训练、推理时外推**（零样本尺寸外推）？
  2. 多频段是**同口径多个离散频点**各自赋形，还是**宽带连续**、且要求同一码在带内同时满足？后者是硬得多的多目标问题。
  3. 异形混排指**按区域分块混排**（如中心/边缘用不同单元），还是**全孔径随机混排**？单元间互耦是否要进模型（现有 M1 主模型是谱形/单元级近似）？

### 0002 · 2026-10-23 · 核心假设的两条独立论证路径（MoM 降维 vs PO 近似）

**原话**：

> 共同的核心假设（也是你在论文里最该引用他的一句）：一个单元上的电磁响应可以用单个复数（宏基函数系数 / 等效权重）概括，整个阵列的远场是这个复数向量的线性泛函。
> 他这句话是拿矩量法证明的（$N M_0 \to N$ 的降维），你是拿物理光学近似论证的（$\gamma_n = \Gamma_{\text{bit}}(1+\delta_n)$）。
> 两条路独立走到同一个"每单元一复数"的表征，这本身就是很强的论文素材。

**要点**

- **共同假设**：单元电磁响应 $\to$ 单个复数（宏基函数系数 / 等效权重）；阵列远场 $\to$ 该复数向量的**线性泛函**。
- **对方的论证**：矩量法（MoM）+ 宏基函数，未知量由 $N M_0$ 降为 $N$（$N$ 为单元数，$M_0$ 为每单元保留的基函数数，`待确认` 确切定义与典型取值）。
- **我们的论证**：物理光学（PO）近似，每单元等效复权重 $\gamma_n = \Gamma_{\text{bit}}(1+\delta_n)$，即"标称码字反射系数 × 单元级修正"。
- **价值**：两条**方法上独立**的路径（数值严格的全波降维 vs 高频近似）收敛到同一表征，可写成"表征假设的独立验证"——把建模选择从"工程近似"抬成"有交叉证据的结论"，正面回应"模型过于简化"的审稿质疑。可作为引言/建模章的一段，或一张"两条路径 $\to$ 同一表征"的示意图。

**备注**

- 这条比精度指标更底层：它决定"远场是 $\gamma$ 的线性映射"这一结构，从而 GNN 只需学 $\text{bit} \to \gamma$（或 $\delta_n$）的非线性，而不必学整个场映射；这也正是"物理主干 + 全局隐变量 + 学每单元修正"路线成立的**理论理由**（此前只是经验上有效）。
- **线性泛函成立的范围**：仅在"固定 $M_0$ 个宏基、忽略更高阶耦合"下严格成立；被截断的高阶耦合项即残差 $\varepsilon$。问题：这个 $\varepsilon$ 与实测的"与编码无关的相干残留 $|b|\approx 0.37$、相位 $\approx 265°$"是否同源？若是，则残留有了第一性解释（截断误差而非工艺/几何背景），`待确认` —— 这会是很强的一节内容。
- **引用策略**：引言/建模部分引对方 MoM 降维做严谨性背书，再把我们的 $\gamma_n$ 公式作为"可直接用于反向设计/训练的工程化落地"，避免只写"我们做了近似"。
- `待确认`：
  1. ~~**"他"的具体出处**（作者/年份/DOI/页码）。~~ **2026-10-23 已确认：Khoram et al., ACS Photonics 2023（DOI 10.1021/acsphotonics.2c01019），见 0003。** 已核查 `文献\张哲2023_全文.txt`：该文 §1.2 提到 SED 基函数"在阵列中每个单元只建立一个全域基函数"（与"每单元一复数"一致，约第 360 行），但**未检索到"远场是复数向量的线性泛函"的原句**，也未找到 $N M_0 \to N$ 的写法——可能出自另一篇/另一处，需你指明。
  2. $M_0$ 的确切含义与量级（每单元保留几个宏基函数？$M_0=1$ 时正是"每单元一复数"），以及 $N M_0 \to N$ 的实际降维比。
  3. 我们的 $\gamma_n=\Gamma_{\text{bit}}(1+\delta_n)$ 与对方 $N M_0$ 截断能否逐项对应——即 $\delta_n$ 是否恰为 $M_0>1$ 项的一阶修正？若能对应，两条路径就不是"类比"而是"同一展开的不同截断"。

### 0003 · 2026-10-23 · 出处确认 + 复现仓库源码解读（Khoram 2023 / aarowz/metasurface-modernized-gnn）

**用户只给了链接**：https://github.com/aarowz/metasurface-modernized-gnn （MIT）

**这解决了 0002 的悬案**："他" = **Khoram, Wu, Qu, Zhou, Yu, "Graph Neural Networks for Metasurface Modeling", ACS Photonics 10(4):892–899, 2023, DOI [10.1021/acsphotonics.2c01019](https://doi.org/10.1021/acsphotonics.2c01019)**（Zongfu Yu 组，威斯康星大学麦迪逊分校）。该仓库是它的 PyTorch Geometric 复现（README 自述 DGL → PyG 现代化）。

**源码要点（我逐文件读的，非 README 转述）**

| 项 | 实现 |
|---|---|
| 图 | 7×7 主窗口 + 6 像素 padding → **19×19 = 361 节点**；连接半径 R=3 圆形邻域，**每节点恰好 29 个邻居（含自身，按 i²+j²≤9 点数正是 29）** |
| 节点特征 | **5 维**：[R 半径, H 高度, D_x 位移, D_y 位移, 边界标记 bnd]，bnd 取 0/1/2 区分外层/次外层/内部——即"每单元 = 一组几何参数" |
| 消息传递 | 邻居特征**按固定顺序拼接**成 29×in_feats，再乘单一权重矩阵；先除距离 1/r 再变换；邻居数 ≠29 的节点输出**直接置零** |
| 输出 | E 场 6 通道 = (Ex,Ey,Ez) 的实/虚部；7×7 窗口 × Ng=24 上采样 → 每样本 168×168 |
| 训练 | 98λ×98λ 大结构上**滑窗采样**（stride 4，augment 抖动 ±2），6 层 GNN + 4 层 CNN 解码 |
| 规模 | 8λ(100 cells) → 80λ(10000 cells) **同一个模型**，目标 MSE ≈0.29（归一化场） |

**关键判断（`待确认`，我的解读，不代你裁决）**

1. **"size-agnostic" 的实质是"局部性 + 固定尺寸滑窗"，不是图规模泛化**：拓扑固定 19×19、邻居数**硬编码 29**、权重维度 $29\times in$，换窗口大小就得改权重。这与 0001 的「可变阵列规模」**不是同一件事**——真要做规模泛化，必须换掉"定长邻居拼接"（改 sum/attention 聚合 + 相对位置编码）。
2. **消息传递对邻居顺序敏感（concat，非置换不变）**：物理上把邻域当"结构化模板"而非"集合"。规则方格阵上成立；但 0001-3 的**异形单元混排 / 非规则布局**下"第 k 个邻居"无定义，此设计**直接失效**——这是一个清晰的"他们做不到、我们可以做"的差异点。
3. **代码里没有"每单元一个复数系数 + 远场线性泛函"的显式实现**：网络直接回归 E 场网格，学的是**场**不是**系数**。说明该假设在论文里是**理论动机/解释**，不是实现约束。我们若把 γ 显式建进模型（0002 的 $\gamma_n$），正好是"物理可解释 vs 端到端黑箱"的差异化位置。
4. **监督目标是近场 E 场**（6 通道网格），不是远场方向图；MSE 0.29 是归一化场误差，**与我们的方向图指标不可直接比较**，别在论文里并排比数字。

**可借鉴**

- 节点特征设计：几何参数直接进特征、bnd 边界标记处理有限阵列截断、1/r 距离权重。
- 滑窗策略：大结构无法整体训练时的标准解法，顺带扩充数据量。
- CNN 上采样解码（单元级 → 像素级场）：适合我们做"口径场 → 远场"的中间表示。
- 可作我们 GNN 的对照基线：同任务、换远场监督，直接暴露"端到端回归场"与"显式 γ + 传播算子"的差距。

**叙事更新**

- 0002 的"两条独立路径"现在有明确对手方：**Khoram 2023（MoM/宏基函数降维）vs 我们（PO + $\gamma_n$）**。论文里可点名比较，并强调我们把"远场 = γ 的线性泛函"写成了**结构**，而不是让网络隐式去学。

**`待确认`**

- 论文正文中"每单元一复数 + 线性泛函"的原句与 MoM 论证细节（仓库 README 未涉及，需拿全文核对；目前只能确认引用指向正确）。
- 仓库 README 勾了 "Results replication [x]"，但 **Our MSE 列全是 TBD** —— 是否真复现成功存疑，**不要直接引用其性能数字**。
- 复现仓库与原论文实现的偏差（PyG 版加了 batch norm / residual；原版是 DGL）——用于对照时需说明。

### 0004 · 2026-10-23 · Khoram 2023 精读完成：0003 的三处更正 + 五项数值核验

**产出**：`文献精读_Khoram2023_GNN超表面.md`（正文 ~630 行）、配图 `fig_paper/fig_khoram_reading.png`、核验脚本 `verify_khoram_equiv.py` + 报告 `verify_khoram_report.txt`。除 PDF 与复现仓库外，另找到**作者官方仓库** `erfan6511/GNN-for-Metasurfaces`（DGL 原版）并逐文件对读，这是 0003 时没有的材料。

**0003 需更正三处**（原话保留不改，仅此处记录修正）：

1. 0003 写"6 层 GNN + 4 层 CNN 解码" → 实际 **7 层**（官方 `nhl=5`，即 1 输入 + 5 隐 + 1 输出）；复现的解码器是 **5 个 3×3 卷积构成的 PixelShuffle 超分网络**，不是"4 层 5×5 CNN"（那是官方实现）。
2. 0003 写"目标 MSE ≈0.29" → 论文 Table 1 的指标是**相对 $L_2$ 范数** $\|I_{\rm net}-I_{\rm sim}\|/\|I_{\rm sim}\|$，不是 MSE；README 的 "MSE" 是误标，且 0.29 是从论文抄的、不是自己跑的。
3. 0003 写"输出 E 场 6 通道" → 官方每节点输出 **$6N_g^2=3456$ 维**（该单元上方 $6\times24\times24$ 的场块），复现压成 **64 维隐向量**再上采样。这不是实现细节，是**换了一个模型**（参数量 532 M vs 24.8 M）。

**新增的关键结论**（正文 §6，前三条已数值验证）：

- **J2**：Eq.(1) 与「7×7 圆形掩膜 conv2d、每 tap 一个独立矩阵」**数值恒等**（$5.4\times10^{-7}$）；1/r 被 $W$ 精确吸收（$2.4\times10^{-7}$），不构成物理先验；该层**不是置换不变的**（仅换邻居枚举顺序，输出偏差 0.65 / 量级 0.42）。
- **J3**：感受野 22 格 vs 补边 6 格 → 0.29 是"局部闭合"的**信息论地板**，可解释 Table 1 里误差对尺寸近乎免疫（0.287–0.291）。
- **数据侧**（挖自 `data_maker.ipynb`，论文正文全未提）：存盘的是**散射场**（总场 − 裸衬底场）；空单元 ≈25%；$a=480$ nm $=0.8\lambda$（故论文"98λ"应为 96λ）。

**对我们的直接影响**（正文 §8）：

- ⚠️ **不要把 Khoram-GNN 当作 M1(CNN) 的对照来证明"GNN 更好"**：在规则阵上两者数学等价，差异只会来自超参噪声。差异只能落在**异构/非规则布局**上——这恰是 0001-3「异形单元混排」的机会，也是我们 M3 用 `MLP_msg + sum`（真正置换不变）而非模板卷积的价值所在。
- 可借：滑窗+补边（把 1000 例变 12 万局部样本）、旋转+分量重排做偏振扩展、"散射场"监督（与我们扣掉标称码字同源）。
- 可做的三个实验见正文 §8.3（halo 曲线 / 置换不变性对照 / 全局支路必要性）。
