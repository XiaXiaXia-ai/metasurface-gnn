## 0. 一句话结论

把 4x4 编码贴片去掉后，ON 态在 z=0 结构面的物理相位会从当前的 **+170.2 度**（几乎就是金属）掉到裸地板附近的 **约 +108 度**；要让它在 10 GHz 回到 **0 度**，需要给顶层补回约 **58 fF** 的等效并联电容。推荐用“方环 + 中央竖条 + 与竖条合并的实心垫片”做这个电容旋钮，几何范围 0.5 到 8.8 mm，全部可加工。主候选是 **wr=2.4, wb=2.4, wp=7.8, hp=6.0 mm**；保守分支是 **wr=0.8, wb=2.2, wp=0 到 8 mm**。两者都已写进 cases.csv，等 CST 可运行后先跑 16 点粗扫。

## 1. 必须先说清楚：这里的 0 度是哪个面

CST 的 Floquet 端口在 Zmax=+7.5 mm，SetDistanceToReferencePlane 为 -7.5。7.5 mm 在 10 GHz 正好约 lambda0/4，所以：

| 量 | 当前 4x4 编码 ON 态 | 全金属（z=0 整片 PEC） |
|---|---:|---:|
| CST 端口相位（z=+7.5） | **-9.92 度** | 0 度（严格 -0.125 度） |
| z=0 结构面物理相位 | **+170.20 度** | **180 度** |
| 两者之差 | 9.80 度 | — |

换算（10 GHz 点频）：

    phi_phys(z=0) = phi_port + 180.12 度，约等于 phi_port + 180 度

全频段更准确：

    phi_phys(f) = phi_port(f) + 360 * f * 7.5 mm / c
                = phi_port(f) + 0.31416 * f(GHz)   [度]

这条关系不是“CST 的固定 180 度约定”，而是 7.5 mm 空气段的往返传播；在 8/9/10/11/12 GHz 分别是 +144.1/+162.1/+180.1/+198.1/+216.2 度。10 GHz 恰好是 180 度，所以下面只写 180 度。

**因此，用户说的“on 态反射相位 0 度”有两种可能：**

| 解释 | 目标 | 相对全金属（180 度）的物理差 | 对 1-bit 编码 |
|---|---|---:|---|
| **A. 物理 0 度（推荐）** | CST port 约 **180 度** | **180 度** | **成立** |
| B. port 0 度 | CST port = 0 度 | 0.1 度 | 不成立，等于又做了一块金属 |

当前 ON 态 port = -9.9 度看起来“接近 0 度”，但物理是 170.2 度，与全金属只差 9.8 度——这正是阵列里看不出编码的原因。**所以本设计按解释 A（物理 0 度）做；如果用户其实要的是 port 0 度，那只需要把结构做得更像金属，不需要本方案。** 这一点请在跑仿真前确认。

## 2. 为什么去掉 4x4 编码贴片后相位会跑掉

当前单元（reflect_ess_on_state.py）：

- 15 mm 周期，3 mm 真空基板，PEC 地板 z=-3，顶层 z=0；
- 4x4 编码贴片：每片 1.5x1.5 mm，**片与片在 x/y 方向是紧挨着的**（没有片间缝），1 的位置有铜、0 的位置是洞；x/y 各镜像一次，共 24 片，铺满中心约 12x12 mm；
- PEC 方环：外 15x15，宽 0.5 mm；两根 1 mm 竖条；两个 RLCSerial（R=3 欧，L=0.45 nH）跨 1 mm 缝，把竖条接到方环；
- 编码贴片块与方环内边之间只有 **0.5 mm 的窄缝**，这是顶层并联电容的主要来源。

去掉贴片后：

1. 0.5 mm 窄缝消失，剩下的环-条缝宽变成 **3.6 到 6.1 mm**；
2. 顶层等效并联电容大幅下降，槽线/AMC 共振频率上移；
3. 在 10 GHz，工作点从“接近金属”退到“接近裸地板”——物理相位约 **+108 度**（裸 3 mm 短路 stub 的解析值 107.95 度），而不是 0 度；
4. 要回到 0 度，必须把顶层并联电纳补到 **+3.65 mS**（等效 58.1 fF @10 GHz）。

**结论：只删贴片、不补电容，相位不会停在 0 度，而是跑到 +108 度附近。** 所以“去掉编码”必须和“加回一个可调的电容结构”一起做。

## 3. 新单元：方环 + 竖条 + 中心垫片

### 3.1 几何

![Proposed unit cell](_sub_unit_cell.png)

图：主候选 wr=2.4, wb=2.4, wp=7.8, hp=6.0 mm；红色为两个 PIN 二极管 ON 等效，跨 1.0 mm 缝；环与竖条之间除这两个集总元件外没有 PEC 连接。

坐标（单元中心为原点，z=0 为金属面）：

    P    = 15.0 mm
    HALF = 7.5 mm
    a    = 7.5 - wr            # 方环内边半宽
    g    = 1.0 mm              # 固定二极管缝
    yb   = a - g = 6.5 - wr    # 竖条半长

| brick | x 范围 | y 范围 | 说明 |
|---|---|---|---|
| 方环 N | [-7.5, 7.5] | [a, 7.5] | 通长 |
| 方环 S | [-7.5, 7.5] | [-7.5, -a] | 通长 |
| 方环 W | [-7.5, -a] | [-a, a] | 夹在中间 |
| 方环 E | [a, 7.5] | [-a, a] | 夹在中间 |
| 竖条 | [-wb/2, wb/2] | [-yb, yb] | 连续一根 |
| 中心垫片 | [-wp/2, wp/2] | [-hp/2, hp/2] | 与竖条 Solid.Add 合并；wp=hp=0 时不建 |
| 基板 | [-7.5, 7.5] | [-7.5, 7.5] | z 在 [-3, 0]，Vacuum |
| 地板 | [-7.5, 7.5] | [-7.5, 7.5] | z=-3，PEC |

两个集总元件：

| 元件 | P1 | P2 | 参数 |
|---|---|---|---|
| 上二极管 | (0, +yb, 0) | (0, +a, 0) | RLCSerial R=3 欧, L=0.45 nH, C=0 |
| 下二极管 | (0, -yb, 0) | (0, -a, 0) | 同上 |

**端口位置必须用 a、yb 公式生成**，不能像旧脚本那样写死 y=+/-6 和 +/-7——旧写法只对 wr=0.5 成立。

### 3.2 尺寸约束

    wr, wb >= 0.5 mm
    s_bar = a - wb/2      >= 0.5 mm     # 竖条侧面到环
    s_pad = a - wp/2      >= 0.5 mm     # 垫片侧面到环
    s_top = a - hp/2      >= 0.5 mm     # 垫片上下到环
    bar_len = 2*yb        <= 13 mm
    max(wp, hp)           <= 8.8 mm     # 本方案实际上限
    hp/2                  <= yb         # 垫片不伸进二极管缝

主候选（wr=2.4, wb=2.4, wp=7.8, hp=6.0）：s_bar=3.9, s_pad=1.2, s_top=2.1, bar_len=8.2 mm，覆盖率约 79.6%，没有占满 15 mm 周期。

**关于“最大金属 13 mm”**：环外边固定 15 mm（周期边界），与“13 mm”按字面冲突。本方案把 13 mm 理解为“除周期环外的最大实心金属尺寸”；若 13 mm 是包括环的硬上限，需要把环外边缩到 13 mm、四周留 1 mm 缝，那是另一组对照，不能和本表混跑。

## 4. 参数往哪个方向调

| 参数 | 对顶层电容 | 对 10 GHz 相位 | 备注 |
|---|---|---|---|
| wb 增大 | 缝变窄，C 上升 | 相位减小（从 +108 度向 0 度、再向负） | 主旋钮之一；wb=3.0 时 s_bar 仍 >=3.6 |
| wp 增大 | 垫片-环缝变窄，C 上升 | 相位减小 | 主旋钮；s_pad 到 0.5 附近饱和 |
| hp 增大 | 窄缝段变长，C 上升 | 相位减小 | 与 wp 解耦用 |
| wr 增大 | 缝变窄但槽长变短，两个效应相反 | 弱、可能非单调 | 只作辅助，不作主调谐 |

**解析预期**：无垫片时相位约 +80 到 +108 度（比裸地板略高，因为环/条有少量感性加载）；加垫片后向 0 度走，垫片过大则变负。主候选 B04 的 s_pad=1.2 mm，预计在 0 度附近；B03（wp=6.6, s_pad=1.8）偏正，B05（wp=8.8, s_pad=0.7）偏负。**这些只是选点排序，不是仿真值。**

### 5.2 判据与下一步

1. 先看 **A00/B00**：无垫片时物理相位应在 +80 到 +108 度。若不在这个区间，说明环/条本身有强感性或共振，先记录，不要急着加垫片。
2. 找 **|物理相位| <= 15 度** 的点。若 B04 在 +/-15 度内，直接进细扫；若 B03 已负、B04 更正，说明过零在 6.6 到 7.8 之间；若 B05 仍正，说明垫片不够强，需加 hp 或 wb。
3. 细扫：在过零区间以 **0.2 到 0.4 mm** 步长扫 wp（固定 wr/wb/hp），目标 **|物理相位| <= 5 度**。
4. 验证：同一点重复建模，相位重复性 <=0.5 度；局部网格 0.25/0.20/0.15 mm 三档，|delta phi| <=2 度；端口放到 z=+10/+15 mm，de-embed 到 z=0，|delta phi| <=0.5 度；锚点 z=0 全金属 = 180.0+/-0.5 度，只有地板 = 108.0+/-1.0 度；锚点不对，先修端口/参考面。
5. 只有以上全部通过，才能把该点称为“10 GHz 物理相位 0 度的 ON 态单元”。
