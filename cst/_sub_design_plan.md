# ESS ON 态相位归零单元胞：参数化与三阶段扫描方案

> **状态：待仿真方案，不是 CST 结果。** 本文件没有运行 CST（本机 CST 启动即崩），
> 所有“预期相位”均为传输线/槽线物理判断，只用于选点和排序，不能当作仿真数据。
>
> **输入锚点（用户提供）**：当前 ESS ON 态在 10 GHz 的物理相位为 **-9.9 deg**，
> |S11| = -1.1 dB。目标：去掉 4x4 编码贴片后，重新设计金属几何，使 ON 态在
> 10 GHz、以 z=0 结构面为参考的物理相位为 **0 deg**（相对 z=0 全金属的 180 deg
> 相差 180 deg）。

## 0. 结论摘要

1. **去掉 4x4 编码贴片后，10 GHz 相位会向正方向走**：贴片-环之间约 0.5 mm 的
   缝隙是主要的分布电容；贴片拿掉后有效缝宽变成 3.9–6.1 mm，电容显著下降，
   槽线/AMC 共振频率上移，10 GHz 落到共振以下，相位从 -9.9 deg 转向
   **约 +50 到 +108 deg**（若剩余环-条呈明显感性，可能更接近 +180 deg）。
2. 因此**需要重新加回电容**。中心垫片不是先验必需，但它是比“继续加宽环/竖条”
   更独立的局部电容旋钮；本方案先用 C01–C06 验证无垫片分支，预期仍需垫片，
   再用 C07–C16 把相位拉过 0 deg。
3. 粗扫 16 点，预计过零点在 **C10–C12**，**C11 为主近零候选**；细扫 12 点以
   0.4 mm 步长在 wp=5.4–8.8 mm 内找 ±5 deg；验证 3 点用 ±0.2 mm 复查斜率，
   并做网格/端口/锚点复核。
4. 所有点满足：最小金属线宽/缝宽 >= 0.5 mm（表中最小实际缝宽 0.70 mm），
   二极管缝固定 1.0 mm，内部实心金属最大尺寸 <= 11.8 mm，中心垫片 <= 8.8 mm，
   最大金属覆盖率 79.6%，没有占满 15 mm 周期。
5. **一个必须确认的约束冲突**：环外边固定 15 mm 与“最大金属尺寸 <= 13 mm”
   按字面冲突。本方案把 13 mm 解释为“除周期边框外”的最大实心金属尺寸；环是
   周期边界上的框，不是 15x15 实心板。若 13 mm 是包括环的硬上限，需要把环外边
   缩到 13 mm、四周留 1.0 mm 缝，这会改变相邻单元耦合，应单独做对照，不能与
   本表混在一起。

## 1. 参数化

### 1.1 固定量

| 量 | 值 | 说明 |
|---|---:|---|
| 周期 P | 15.0 mm | 方形单元，x/y 均 15 mm |
| 基板 | 3.0 mm 真空 | z in [-3, 0] mm |
| 地板 | PEC，z=-3.0 mm | 与单元边界同宽 |
| 顶层金属 | PEC，z=0 | 零厚度片；实际铜箔可后续加 0.035 mm |
| 二极管缝 g | **1.0 mm** | 固定，不随 wr 变 |
| PIN ON | R=3 ohm, L=0.45 nH, C=0 | 10 GHz 时 Z_d=3+j28.27 ohm，abs(Z_d)=28.4 ohm |
| 入射 | 正入射，E//x | Floquet TE(0,0)/TM(0,0) |

### 1.2 可调量

| 符号 | 含义 | 建议范围 | 约束 |
|---|---|---:|---|
| wr | 方环宽度 | 0.6–2.4 mm | >=0.5；环外边固定 15 |
| wb | 中央竖条宽度 | 1.6–3.0 mm | >=0.5；不能碰环 |
| wp | 中心垫片宽度（x） | 0 或 3.0–8.8 mm | 0=不加；否则 >=wb+0.2，且留缝 >=0.5 |
| hp | 中心垫片高度（y） | 0 或 1.5–8.0 mm | 0=不加；否则留缝 >=0.5 |

**垫片的 CAD 语义（本方案选定）**：中心垫片是**与竖条布尔合并的实心矩形凸台**，
不是悬浮岛。也就是说，竖条在中心局部加宽到 wp，加宽段高度为 hp；整个
“竖条+垫片”仍是一个中心导体，只通过上下两个集总元件与环相连。这样不会引入
第三条导体和额外缝隙，拓扑最简单。若以后要做“悬浮垫片”，必须把竖条切断并在
垫片上下各留 >=0.5 mm 缝，那是另一个结构，不能套用本表。

### 1.3 坐标公式（单元中心为原点）

~~~text
P   = 15.0
H0  = P/2 = 7.5
a   = H0 - wr = 7.5 - wr          # 环内边半宽
g   = 1.0                          # 固定二极管缝
yb  = a - g = 6.5 - wr             # 竖条半长（条端到中心）
~~~

所有顶层金属在 z=0，厚度取 0（PEC 片）。砖块坐标：

| brick | x 范围 (mm) | y 范围 (mm) | z | 备注 |
|---|---|---|---:|---|
| 环-下 | [-7.5, +7.5] | [-7.5, -a] | 0 | 全宽，和左右条在角部重叠 |
| 环-上 | [-7.5, +7.5] | [+a, +7.5] | 0 | 全宽 |
| 环-左 | [-7.5, -a] | [-a, +a] | 0 | 连接上下条 |
| 环-右 | [+a, +7.5] | [-a, +a] | 0 | 连接上下条 |
| 竖条 | [-wb/2, +wb/2] | [-yb, +yb] | 0 | 连续一根；上下端各接一个二极管 |
| 中心垫片 | [-wp/2, +wp/2] | [-hp/2, +hp/2] | 0 | **与竖条 union**；wp=0 或 hp=0 时不建 |
| 基板 | [-7.5, +7.5] | [-7.5, +7.5] | [-3, 0] | Vacuum |
| 地板 | [-7.5, +7.5] | [-7.5, +7.5] | -3 | PEC |

环的四块在角部互相重叠；布尔 union 后是一个闭合方环。**环与竖条/垫片不要
union**（或至少保证 1.0 mm 缝内没有任何 PEC），否则会短路二极管。

### 1.4 两个集总元件

| 元件 | P1 (mm) | P2 (mm) | 方向 | 参数 |
|---|---|---|---|---|
| 上二极管 | (0, +yb, 0) | (0, +a, 0) | +y | R=3 ohm, L=0.45 nH, C=0 |
| 下二极管 | (0, -yb, 0) | (0, -a, 0) | -y | 同上 |

端口长度恒为 a-yb = g = 1.0 mm。wr 改变时，a 和 yb 同时平移，两个
端口必须用公式生成，不能写死 y=+-6 和 y=+-7（旧版就是固定值，只对
wr=0.5 成立）。

### 1.5 关键间隙与尺寸校验

~~~text
s_bar = a - wb/2        # 竖条侧面到环内边的水平缝
s_pad = a - wp/2        # 垫片侧面到环内边的水平缝（有垫片时）
s_top = a - hp/2        # 垫片上/下边到环内边的垂直缝（有垫片时）
bar_len = 2*yb = 13 - 2*wr
~~~

约束：

~~~text
wr, wb >= 0.5
s_bar, s_pad, s_top >= 0.5
bar_len <= 13
max(wp, hp) <= 13
wp/2 < a - 0.5, hp/2 < a - 0.5   # 垫片绝不碰环
~~~

极值点校验（C12，最大加载）：

~~~text
wr=2.4, wb=2.4, wp=8.8, hp=6.0
a=5.1, yb=4.1
s_bar=3.9, s_pad=0.70, s_top=2.10
bar_len=8.2, pad max=8.8, coverage=79.6%
~~~

最稀疏点 C01：bar_len=11.8, s_bar=6.1, coverage=23.8%。两端都没有
把 15 mm 周期占满。

### 1.6 关于“最大金属尺寸 13 mm”与“环外 15 mm”

这是本方案唯一需要上游拍板的约束歧义：

- 若 13 mm 指**除周期环以外**的最大实心金属：本表全部满足（最大内部尺寸
  11.8 mm，垫片 8.8 mm）。环是周期边界上的框，外 15 mm 是晶格周期，不是
  一块 15x15 的实心金属。
- 若 13 mm 是**包括环**的硬上限：把环外边改成 13.0 mm，四周各留 1.0 mm 空缝。
  这会引入环-相邻环之间的额外缝，改变互耦和槽线共振，必须另做一组
  “outer=13” 的对照，不能直接把本表数值搬过去。

## 2. 物理判断：去掉贴片后相位往哪走

### 2.1 10 GHz 的传输线锚点

把 z=0 以下看成一段 3 mm 真空短路线，其输入导纳为：

~~~text
Y0 = 1/eta0 = 2.654 mS
beta*h = 2*pi*f*h/c = 0.6288 rad = 36.02 deg
Yg = -j*Y0*cot(beta*h) = -j*3.650 mS
Yin = Ys + Yg
Gamma = (Y0 - Yin)/(Y0 + Yin)
~~~

- 无顶层金属（只有地板）时，Ys=0，Gamma 相位 = **+107.95 deg**。
- z=0 全金属（PEC 短路）时，Gamma=-1，相位 = **180 deg**。
- 要得到目标 Gamma=+1（物理相位 0 deg），需要 Yin=0，即顶层提供
  **Bs = +3.650 mS 的净电容性电纳**。若把 Bs 等效成 omega*C：

~~~text
C_eq = 3.650 mS / (2*pi*10 GHz) = 58.1 fF   (每 15x15 mm 单元)
~~~

这就是本设计的定量锚点：整个单元只需要约 **58 fF** 的有效 shunt 电容，
不是“金属越多越好”。

由用户给的 -9.9 deg 反演（同一 z=0 参考面）：

~~~text
tan(4.95 deg) = 0.0866
Bs = Yg + 0.0866*Y0 = 3.650 + 0.230 = 3.880 mS
C_eq = 61.8 fF
~~~

也就是说，当前带贴片的 ON 态只比目标电容高约 **6%**（0.23 mS），已经
非常接近 0 deg；这也解释了为什么它看起来“几乎就是一块金属”，相位却恰好
在 -10 deg 附近。

相位对 Bs 的灵敏度（在共振点附近）：

~~~text
d(phi)/d(Bs) = -2/Y0 = -753.5 rad/S = -43.2 deg/mS
|phi| <= 15 deg  <=>  |Bs - 3.650 mS| <= 0.347 mS  <=>  |C_eq - 58.1 fF| <= 5.5 fF
~~~

**这意味着相位对几何非常敏感**：细扫 0.2–0.4 mm 的步长不是浪费，是必要的；
粗扫若步长太大，很容易从 +20 deg 直接跳到 -20 deg。

Bs 与相位的一阶关系（仅作选点直觉）：

| Bs (mS) | -2.0 | 0 | 1.0 | 2.0 | 3.0 | 3.650 | 4.0 | 5.0 |
|---:|---:|---:|---:|---:|---:|---:|---:|---:|
| phi (deg) | +129.7 | +108.0 | +89.9 | +63.7 | +27.5 | **0** | -15.0 | -53.9 |

### 2.2 去掉 4x4 贴片：相位向正方向走

当前贴片阵列的关键作用不是“当一块金属”，而是提供贴片边缘到环之间约
**0.5 mm 的窄缝电容**。这个窄缝是顶层 shunt 电容的主要来源，和 3 mm 短路线
的电感一起把共振拉到 10 GHz 附近。

去掉贴片后：

1. 有效缝宽从约 0.5 mm 变成 s_bar = 3.9–6.1 mm；
2. 单位长度槽线电容随缝宽增大而下降，总 C_eq 明显降低；
3. 槽线/AMC 共振频率 f0 ~ 1/sqrt(L_eq*C_eq) 上移；
4. 在固定 10 GHz，工作点从“略高于共振”（-9.9 deg）移到“低于共振”，
   Bs 变小甚至变负，相位向正方向旋转。

预期范围：**+50 到 +108 deg**。如果剩余环-条结构呈明显的感性（细条、大孔），
相位可能进一步靠近 +180 deg。**不会停留在 -10 deg 附近，也不会自动变成 0 deg。**
这正是为什么“只删贴片、不补电容”不可行。

### 2.3 为什么需要/不需要中心垫片

**不是先验必需。** 理论上加宽 wb 或 wr 也能增加槽线电容，把相位拉回来。
但：

- wb 加宽会让竖条-环缝变窄，直到碰环；最大 wb=3.0 时 s_bar 仍有
  3.6 mm，调节量有限。
- wr 加宽同时产生两个相反效果：缝变窄（C' 上升）但环内边内移、竖条和槽线
  长度变短（总 C 下降）。所以 wr 不是单调性很好的主旋钮，详见 2.4。
- 中心垫片只在 hp 高度内把缝从 s_bar 局部收窄到 s_pad，是**局部、
  可独立、不会把整个孔径关掉**的电容旋钮；适合做最后 0.3 mS 的微调。

因此扫描策略是：**C01–C06 先验证“不加垫片能否到 0”；若 C06 仍明显为正，
则 C07–C16 用垫片把相位拉过 0。** 如果 C06 已经 <=0，垫片可以取 0，直接
在 C04–C06 附近做细扫，不必强行加垫片。

### 2.4 wr / wb / wp / hp 的单调性预期

约定：“相位减小”指从正角（+90…+180）向 0、再向负角方向旋转；若孔径完全
关闭，结构退化为 PEC，相位会从 -180 回绕到 +180，这时单调性失效。

| 参数 | 对有效电容/电纳的预期 | 对 10 GHz 相位的预期 | 可信度与注意 |
|---|---|---|---|
| wb 增大 | s_bar 减小，槽线 C' 上升；条长不变 | **相位减小（单调）** | 高；直到 s_bar 接近 0.5 或结构趋于 PEC |
| wp 增大 | 垫片段 s_pad 减小，局部 C 上升 | **相位减小（单调）** | 高；s_pad 到 0.5 附近饱和，再关就回绕 |
| hp 增大 | 窄缝段长度增加，总 C 上升 | **相位减小（单调）** | 高；hp -> 2a 时饱和 |
| wr 增大 | 缝变窄使 C' 上升，但 a、yb 变短使总长度下降 | **弱、可能非单调** | 低；只做 0.6–2.4 的辅助扫描，不作主旋钮 |
| g 固定 1.0 | 二极管缝，不是几何调节量 | — | 固定；改变会同时改变负载电抗和加工 |

wr 的竞争效应值得强调：从 0.6 加到 2.4，a 从 6.9 降到 5.1（槽长 -26%），
s_bar（wb=1.6 时）从 6.1 降到 4.3（缝宽 -30%）。C' 的上升可能被长度下降
抵消，所以不能指望“环越宽相位越负”。本表把 wr 放在 C01–C04 只是为了看
趋势和给后续点一个边界，不把它当精密调谐量。

## 3. 三阶段扫描方案

### 3.1 总策略

~~~text
粗扫 16 点  ->  找 |phi|<=15 deg 的点，且必须有正有负（或至少一个近零）
细扫 12 点  ->  在过零区间内以 0.4 mm 步长找 |phi|<=5 deg
验证 3 点   ->  最优点 +-0.2 mm，复查斜率、网格、端口、锚点
~~~

所有点都在 10.0 GHz、正入射、z=0 参考面记录：

~~~text
phi_phys = arg(S11) at z=0 (unwrapped)
|S11| in dB
f0 = frequency where phi crosses 0 (from 8-12 GHz sweep)
coverage, min slot, Z_diode
~~~

**粗扫通过判据**：至少一个点 |phi_phys| <= 15 deg。若没有，不进入细扫；
先用最接近 0 的正、负两点做二分/插值，检查是不是步长太大或共振跑出 8–12 GHz。

**选点依据**：

- C01–C04：固定 wb=1.6、无垫片，只扫 wr，用 4 点判断“环宽”到底往哪走。
  这四点不是主调谐，是为后续点定边界。
- C05–C06：固定 wr=2.4，把 wb 从 1.6 加到 3.0，验证“竖条加宽”是否是
  足够强的负向旋钮。若 C06 已 <=0，说明不需要垫片。
- C07–C12：固定 wr=wb=2.4, hp=6.0，把 wp 从 3.0 以约 1.0–1.2 mm 步长
  加到 8.8；这是最可能过零的分支。C11 放在 s_pad=1.2 mm，C12 放在
  s_pad=0.7 mm，用一正一负夹住 0。
- C13–C16：固定 wp=7.8，扫 hp=1.5, 3, 5, 7，把“垫片高度”与“垫片宽度”
  解耦；同时检查 C11 附近对 hp 的敏感度，防止过零靠的是某个偶然的槽线共振。

## 4. 风险与检查方法

| # | 风险 | 机理 | 检查方法 | 触发后的动作 |
|---:|---|---|---|---|
| 1 | **环-竖条槽线共振落在 10 GHz 之外** | 去贴片后 C 下降、f0 上移；垫片过强又把 f0 拉到 10 GHz 以下。15 mm 周期 = 0.50 lambda0，结构不是亚波长等效媒质，槽线共振可能很窄 | 每个点扫 8–12 GHz，找 phi=0 的 f0；要求 f0 在 9.7–10.3 GHz，且 10 GHz 附近相位单调、无跳变。看 10 GHz 表面电流：若电流集中在环/条而非缝，可能是环共振 | f0 太高 -> 加 hp/wp 或 wb；f0 太低 -> 减 hp/wp。若 f0 在带外且 10 GHz 相位平缓，记录并换结构，不要硬调 |
| 2 | **垫片与竖条合并后缝宽/特征变化** | 垫片是 union 到竖条的凸台；布尔运算可能产生 0.1 mm 级 sliver，或把 s_pad 算错 | 在 y=0、y=+-hp/2 取截面，量 s_pad、s_top；DRC 检查最小金属宽度/缝宽 >=0.5；确认垫片与环无接触；检查 union 后的实体数和连通性 | 若出现 sliver，调整 wp/hp 到 0.1 mm 网格；若 s_pad<0.5，减 wp 或加 wr；不要用“视觉上差不多”代替量测 |
| 3 | **集总元件端口位置随 wr 变化** | a=7.5-wr, yb=6.5-wr；旧版写死 y=+-6/+-7，只对 wr=0.5 成立 | 用参数公式生成 P1/P2；在 wr=0.6 和 2.4 两个极端检查端口长度恰为 1.0 mm、端点落在 PEC 边缘、无重叠；做“开路缝”和“PEC 短接”对照 | 端口漂移 -> 改成 a、yb 表达式；端口悬空 -> 让端点与金属面重合 0.02–0.05 mm；不要用固定坐标 |
| 4 | **网格对 0.5–0.7 mm 缝的收敛性** | 最小缝 0.70 mm（C12/F10），二极管缝 1.0 mm；四面体/六面体网格在窄缝和垫片 reentrant 角处容易欠采样 | 局部网格 0.25 / 0.20 / 0.15 mm 三档；最小缝内至少 3 个网格；比较 abs(dphi)<=2 deg、abs(dS11)<=0.2 dB；开 2 passes 自适应，看 Delta S | 未收敛 -> 局部加密到 0.15 mm，或把 s_pad 从 0.7 放宽到 >=1.0；不要用全局加密（单元数爆炸） |
| 5 | **过金属化 / 相位回绕** | 垫片继续加宽、缝接近关闭时，结构趋于 PEC，相位从 -180 回绕到 +180；此时“相位随 wp 单调下降”失效 | 监控 coverage（本表最大 79.6%）、s_pad、s_top；相位 unwrap 后看是否连续；若从 -170 跳到 +170，说明已到 PEC 极限 | 退回上一个缝 >=0.7 mm 的点；不要用回绕后的 +180 当作“过零” |
| 6 | **13 mm 上限与环外 15 mm 冲突** | 环是周期边框，外 15 是晶格周期；按字面 13 无法同时成立 | 与上游确认 13 mm 的定义；若为硬上限，建 outer=13、四周 1.0 mm 缝的对照 | 确认前不要把本表称为“满足 13 mm 硬上限”；对照工程单独编号，不混入本表 |
| 7 | **二极管损耗 / 低 S11 影响相位判读** | R=3 ohm 在 10 GHz 不是理想短路；当前 S11=-1.1 dB 表示有损。损耗会降低相位斜率、让 S11 偏离 1 | 记录 1-abs(S11)^2；用 R=0 理想管对照，分离“几何相位”和“损耗”；不要用增加损耗来换相位 | 若目标点 S11<-3 dB，相位仍可报，但编码对比度差；向 parent 说明，不要隐瞒 |
| 8 | **周期边界/环与邻胞相接** | 环外边 15 与周期边界重合，相邻单元环是连通的；若网格/边界没对齐，会引入额外缝或短路 | 检查 X/Y 边界在 +-7.5，环外边正好落在边界；单元边界设 unit cell；看网格是否在边界连续 | 边界错位 -> 修几何；若要隔离环，改用 outer=14.5 或 13 的对照 |

### 5.1 模型/边界

~~~text
Units: mm, GHz
Frequency: 8-12 GHz, monitor 10.0 GHz
Boundary X/Y: unit cell
~~~

- 地板在 z=-3，PEC；基板 z in [-3,0] 真空。
- 顶层 PEC 片 z=0；环、竖条/垫片分开建，缝内不能有 PEC。
- 端口离结构至少 lambda/4（7.5 mm），建议 z=+10 或 +15。

### 5.2 求解器/网格

~~~text
Solver: Frequency Domain, tetrahedral
Adaptive mesh: on, 2 passes, Delta S <= 0.01
Global max edge: ~1.0 mm (lambda0/30)
Local mesh: 0.25 mm on all top-metal edges and slots
Min slot: 0.70 mm -> at least 3 cells across
Diode gap: 1.0 mm -> at least 3-4 cells
~~~

时间域 TLM 也可做快速筛查，但相位 0 deg 的最终点建议用频域四面体 + Floquet
复核；两套求解器的相位差应 <3 deg，否则以网格收敛的一套为准。

### 5.3 集总元件

~~~text
Type: RLCSerial
R=3 ohm, L=0.45 nH, C=0, Gs=0
P1=(0, yb, 0), P2=(0, a, 0)      # 上
P1=(0,-yb, 0), P2=(0,-a, 0)      # 下
Orientation: along +y / -y
~~~

检查端口是否与 PEC 面接触；CST 的 lumped element 是独立电路元件，不参与
布尔 union。若端口悬空 0.1 mm，结果会变成“电容耦合”，相位会偏。

### 5.4 后处理

每个点导出：

~~~text
ID, wr, wb, wp, hp, f_ghz, |S11|_dB, arg(S11)_deg (z=0, unwrapped), f0_ghz, notes
~~~

绘制：

- phi vs f 8–12 GHz，标出 10 GHz 和 f0；
- phi vs wp（固定 wr/wb/hp），看斜率与过零；
- |S11| vs f，排除深陷波/强损耗点；
- 10 GHz 表面电流/电场截面，确认能量确实进入环-条缝，而不是被环挡在外面。

~~~python
P, H0, g = 15.0, 7.5, 1.0

def cell(wr, wb, wp, hp):
    a  = H0 - wr
    yb = a - g
    s_bar = a - wb/2
    s_pad = a - wp/2 if wp > 0 and hp > 0 else None
    s_top = a - hp/2 if wp > 0 and hp > 0 else None
    assert wr >= 0.5 and wb >= 0.5
    assert s_bar >= 0.5
    assert s_pad is None or s_pad >= 0.5
    assert s_top is None or s_top >= 0.5
    assert 2*yb <= 13
    assert wp <= 13 and hp <= 13
    assert wp == 0 or wp >= wb + 0.2
    return dict(a=a, yb=yb, s_bar=s_bar, s_pad=s_pad, s_top=s_top,
                bar_len=2*yb, gap=a-yb)
~~~
