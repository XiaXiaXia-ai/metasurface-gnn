# CST 相位锚点与关键更正（2026-11-12 17:15）

## 结论

用同一套 15 mm 单元、3 mm 真空、PEC 地板 z=-3、Floquet 口 Zmax=+7.5、参考面 -7.5 mm 的 CST 频域模型，直接跑了三个锚点：

| 模型 | 10 GHz 端口相位 | S11 dB | 说明 |
|---|---:|---:|---|
| 全金属顶层（z=0 整片 PEC） | -180.0 度 | 0.000 | 物理 180 度 |
| 只有地板（无顶层金属） | +107.95 度 | -0.000 | 与 3 mm 短路 stub 解析值 107.95 度一致 |
| 旧 ESS on 态（4x4 编码贴片 + R=3/L=0.45nH） | -9.921 度 | -1.107 | 与旧工程 code1110_on.cst 完全一致 |

因此：SetDistanceToReferencePlane -7.5 已经把参考面移到 z=0，端口相位就是 z=0 的物理相位，没有额外的 +180 度偏移。

之前 _sub_phase_memo.md 里“物理 = 端口 + 180 度、旧 on 态物理 170.2 度”的结论是错的。它把 7.5 mm 空气段的往返相位又加了一次；实际上 CST 的 de-embed 已经把它去掉了。正确关系是：

    phi_phys(z=0) = phi_port        （本模型，10 GHz 及全带）

## 旧 ESS on 态的真实相位

- 旧工程 D:/re_cst_code1110/code1110_on.cst：10 GHz 端口 -9.921 度，S11 -1.107 dB；
- 用旧脚本 reflect_ess_on_state.py 在当前 CST 重跑（先 ChangeSolverType，再 build）：端口 -9.921 度，S11 -1.107 dB，逐位复现；
- 所以旧 on 态在 z=0 的物理相位就是 -9.9 度，已经非常接近 0 度，而不是 170.2 度。

这也意味着：上一轮“on 态几乎就是金属、阵列看不出编码是因为 on 态金属化”的判断，前提不成立。旧 on 态与全金属（180 度）相差约 190 度，1-bit 对比在单元层面是成立的。

## 去掉 4x4 贴片后的新结构（方环 + 竖条 + 垫片）

在同一 CST 频域模型里跑了以下点（无编码贴片，只有方环/竖条/可选垫片）：

| 点 | wr | wb | wp | hp | 端口相位 | S11 dB |
|---|---:|---:|---:|---:|---:|---:|
| B04 | 2.4 | 2.4 | 7.8 | 6.0 | +166.24 度 | -0.035 |
| B00 | 2.4 | 2.4 | 0 | 0 | +167.34 度 | -0.028 |
| R08 | 0.8 | 2.4 | 0 | 0 | +149.13 度 | -0.045 |
| R32 | 3.2 | 2.4 | 0 | 0 | +172.20 度 | -0.020 |
| R48 | 4.8 | 2.4 | 0 | 0 | +177.99 度 | -0.007 |
| R56 | 5.6 | 2.4 | 0 | 0 | +179.25 度 | -0.002 |

规律：环越宽，相位越靠近 180 度（金属态）；中心垫片在 0–8.8 mm 内几乎不起作用（B00/B01/B02/B04/B05 都在 165–167 度）；竖条宽度也几乎不起作用（1.2/2.4/3.0 都是 166–167 度）。

所以“去掉 4x4 贴片、只调方环/竖条/垫片”这条路，是把相位从旧 on 态的 -9.9 度推向 180 度金属态，方向正好相反，不能实现 0 度。

## 旧单元的金属微调

为了看能否把 -9.9 度微调到 0 度，只改方环宽度 RING_W（贴片图案不变）：

| RING_W | 端口相位 | S11 dB |
|---:|---:|---:|
| 0.35 | -138.98 度 | -0.0007 |
| 0.40 | -140.32 度 | -0.0006 |
| 0.50 | -9.921 度 | -1.107 |
| 0.60 | -20.70 度 | -1.147 |
| 0.70 | -23.08 度 | -1.198 |

这是一个高 Q 的共振结构：0.4 到 0.5 mm 之间相位从 -140 度跳到 -10 度，0.5 到 0.6 又回到 -21 度。不能靠粗调环宽来稳定命中 0 度；要精确 0 度，需要更细的参数（贴片-环缝、贴片尺寸）和网格收敛控制。

## 全 16 片（去掉 0/1 孔洞）的对照

把 CODE4 全填 1（中心 6x6 区域变成实心贴片块，不再是编码图案）：

- 10 GHz 端口 +75.03 度，S11 -0.592 dB。

说明：把编码孔洞填满会把相位从 -9.9 度推到 +75 度（更金属化），也不是 0 度。4x4 图案里的孔洞/窄缝是形成 0 度共振的一部分，不能简单删掉。

## 对阵列“看不出编码”的影响

单元层面旧 on 态是 -9.9 度、全金属是 180 度，理论上对比约 190 度，编码应该有效。阵列里看不到编码，更可能是：

1. TLM 网格没有分辨 0.5/1.0 mm 的贴片缝和二极管缝，把 ESS 单元短路成金属；
2. 阵列的 coding 0 是 30x30 整片金属、coding 1 是 4 个 15x15 ESS 子单元，局部周期/互耦不同，单元相位不能直接搬到阵列；
3. 编码矩阵/激励/远场后处理有误。

建议先不要继续改单元几何；先用更细网格（或频域）复算一个 2x2 宏单元小阵列，确认 coding 1 在阵中是否仍有约 0 度相位。这一步比继续扫方环更能定位问题。

## 建议的下一步（三选一）

1. 保留 4x4 纹理、只去掉阵列级编码：把 ESS 单元均匀铺满，on 态就是 -9.9 度（约 0 度），不需要改金属几何；这是最稳的“无编码”方案。
2. 要严格 0.0 度：在旧单元上细扫“贴片-环缝”或“贴片尺寸”（0.05 mm 步长），并做 0.2/0.15 mm 局部网格收敛；不要用方环宽度做粗调。
3. 仍想用无贴片的方环/竖条结构：需要把目标改成“相位尽量接近 0 度”或换结构（例如均匀小贴片阵列/交错电容），当前方环+垫片方向到不了 0 度。
